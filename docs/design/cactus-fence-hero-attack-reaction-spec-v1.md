# DB-004 仙人掌围栏英雄受击反应规范 v1

本规范对应 `protocolVersion 24`、`rulesetVersion prototype-0.35` 与内容版本 27。

## 权威规则

- 仙人掌围栏是费用 2、5 点生命、占用 1 个建筑格的植物 / 防御建筑。
- 每个围栏独立监听每个行动回合内第一次由敌方生物对己方英雄完成的普通攻击。攻击必须已经通过嘲讽与攻击资格校验并对英雄结算伤害。
- 触发后，围栏对该攻击生物造成 1 点伤害。英雄使用装备攻击不属于“生物攻击”，不会触发围栏；攻击其他生物、建筑或结构也不会触发。
- 多个尚未触发的围栏按建筑格、实例 ID 的稳定顺序依次结算。同一攻击者被前一个围栏杀死后，后续围栏停止结算且保持待触发状态。
- 围栏反伤造成的死亡立即进入统一死亡、亡语与掉落流程，击杀归属为围栏控制者。

## 状态与事件顺序

- 每回合触发键为 `<fenceInstanceId>:effect.db_004.01`，存储在围栏控制者的 `triggeredEffectKeysThisTurn` 中；任一行动回合结束时双方标记统一清空。
- 事件顺序为：英雄伤害结果 `ATTACK_RESOLVED` → 每个围栏的 `OBJECT_STATS_CHANGED` → 可选死亡、亡语及掉落事件 → 可选 `MATCH_ENDED`。
- 围栏伤害事件使用 `sourceCardId = db_004`、真实围栏 `sourceInstanceId`、`effectId = effect.db_004.01`、`reason = DAMAGE`，并携带攻击者最终属性。
- `protocolVersion 24` 将 `db_004` 纳入快照中每回合效果标记的合法集合；Unity 同时补齐原先遗漏的 `pf_005` 苗圃标记校验。

## Unity 表现

- 待触发围栏所在真实建筑地表显示低强度沙漠金 / 仙人掌绿色脉冲；触发后地表恢复普通材质，铭牌显示“本回合已触发”。
- 反伤事件脉冲围栏来源与受伤攻击者，并显示“尖刺反击”横幅。
- 建筑使用 Minecraft 仙人掌侧面、顶部纹理与红砂岩基座组合的体素围栏模型，不使用通用双塔占位结构。
