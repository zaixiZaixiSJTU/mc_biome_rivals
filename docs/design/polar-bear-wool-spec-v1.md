# SI-005 北极熊 / TK-001 羊毛：规则契约 v1

状态：SI-005、临时生命协议基础设施与 TK-001 均已实现
当前组合：`protocolVersion 32`、`rulesetVersion prototype-0.51`、内容版本 42

本文冻结两张牌的权威语义。RULE-030B 已完成北极熊纵向切片，RULE-030C 已建立临时生命协议基础设施，RULE-030D 已实现羊毛；集成演示与发布前验证留给 RULE-030E。

## 1. 规范文本

| ID | 名称 | 费用与属性 | 冻结后的规则文本 |
|---|---|---|---|
| SI-005 | 北极熊 | 4 费，3/6，生物，动物 | **嘲讽。部署时，若己方英雄生命值不高于 15，本牌获得 +1 攻击力。** |
| TK-001 | 羊毛 | 0 费，材料，衍生牌 | **使一个己方生物本回合获得 +0/+1。** |

“部署时”是北极熊效果的唯一检查窗口。“本回合”遵循 GDD：只指当前行动玩家的当前回合，并在该玩家结束阶段的“清除本回合效果”步骤移除。

## 2. SI-005 北极熊

### 2.1 条件与持续时间

- 北极熊正常占用一个己方单位格并自带 `TAUNT`；嘲讽不依赖生命条件。
- 付款、移出手牌和创建战场实例后，先公开基础 3/6 的 `CARD_DEPLOYED`，再结算现有入场监听，最后结算北极熊自身效果。
- 在自身效果开始结算的瞬间读取其控制者英雄的权威当前生命。生命小于或等于 15 时，当前战场实例永久获得 `+1` 攻击；16 或更高时不获得。
- “永久”只持续到这个战场实例离场。英雄之后受到伤害不会补发加成，之后受到治疗也不会移除加成；若该牌以后以新实例再次部署，则重新检查。
- 护甲不计入阈值；只读取英雄 `life`。生命恰好为 15 时满足条件。

### 2.2 权威事件

满足条件时顺序固定为：

1. `CARD_DEPLOYED`：公开北极熊基础攻击 3、基础生命 6、`TAUNT` 和稳定实例 ID。
2. 现有入场光环与“召唤己方动物后”监听按既有顺序结算。
3. `OBJECT_STATS_CHANGED`：`reason = PERMANENT_STAT_MODIFIER`，`sourceCardId = si_005`，`sourceInstanceId =` 北极熊实例，`effectId = effect.si_005.01`；携带结算后的最终攻击、当前生命、最大生命和所有已存在的属性修正字段。
4. 现有“打出牌后”监听继续结算。

不满足条件时只有正常部署及其既有监听事件，不发送数值未变化的北极熊属性事件，也不创建隐藏触发标记。

## 3. TK-001 羊毛

### 3.1 合法目标与原子性

- 羊毛是可以在己方主行动阶段主动打出的 0 费材料牌，仍必须位于当前玩家手牌中。
- 命令必须使用 `targetType = UNIT` 并提供一个稳定 `targetInstanceId`。
- 唯一合法目标是当前仍在己方战场上且 `health > 0` 的 `UNIT`。己方建筑、己方结构、己方英雄、敌方对象、已死亡对象、已离场实例和不存在的实例都不合法。
- 在改变任何权威状态前，必须一次性验证行动权、阶段、待决选择、卡牌、目标、控制权和费用。拒绝命令时：不扣红石、不移出手牌、不进入弃牌堆、不增加 `cardsPlayedThisTurn`、不改变目标、不推进 revision、不写已处理命令 ID，也不发布事件。
- 0 费不等于免校验。合法结算后，羊毛离开手牌并公开进入弃牌堆，照常计为本回合打出的一张牌。

### 3.2 属性模型

- 每次结算同时令目标 `maxHealth += 1`、`health += 1`、`temporaryHealthModifier += 1`，并把过期回合绑定为当前权威 `turn`。
- 这不是治疗：增加当前生命不受结算前最大生命限制，事件原因不是 `HEAL`，也不触发“受到治疗”类监听。
- 同一回合对同一目标使用多张羊毛时线性叠加。两张羊毛产生 `+0/+2`，但共享同一个过期回合。
- 其他永久生命修正与相邻光环独立存在。过期时只减去累计的 `temporaryHealthModifier`，不得重算或抹除其他来源。
- 目标在过期前离场时，其临时修正随实例销毁，不产生孤立的过期事件。

### 3.3 过期与生命夹取

羊毛在施放者的结束阶段中，位于“回合结束触发 → 状态效果与持续时间 → 清除本回合效果”顺序的最后一步过期，并早于 `TURN_ENDED`：

1. `maxHealth -= temporaryHealthModifier`。
2. `health = min(health, maxHealth)`；过期不是伤害，不触发受伤、击杀或死亡效果。
3. `temporaryHealthModifier = 0`，`temporaryHealthModifierExpiresOnTurn = 0`。
4. 发布一个 `OBJECT_STATS_CHANGED(reason = TEMPORARY_EXPIRED)`，公开清除后的最终数值。

如果前置结束阶段效果已经使目标死亡并离场，则不再发布该对象的过期事件。如果前置结算已结束整场对局，停止后续回合清理，最终快照可以保留不再参与游戏的临时值。

### 3.4 权威事件

合法施放顺序固定为：

1. `CARD_PLAYED`：公开 `cardId = tk_001`、`effectId = effect.tk_001.01`、最终红石、手牌数、弃牌数与本回合出牌数。
2. `OBJECT_STATS_CHANGED`：`reason = TEMPORARY_HEALTH_MODIFIER`，目标为选中的己方生物；`sourceCardId = tk_001`，`sourceInstanceId = effect-<CARD_PLAYED eventId>`，`effectId = effect.tk_001.01`；携带最终攻击、当前生命、最大生命、临时攻击与临时生命字段及其过期回合。
3. 现有“打出牌后”监听按既有规则继续结算。

每张羊毛各产生一个属性事件。过期时同一对象无论叠加几层都只产生一个 `TEMPORARY_EXPIRED` 事件；该事件无主动卡牌来源，`sourceCardId`、`sourceInstanceId` 与 `effectId` 均为 `null`。

## 4. 示例

| 初始状态 | 操作 | 羊毛结算后 | 回合中后续变化 | 过期后 |
|---|---|---|---|---|
| 3/6 北极熊，当前生命 6 | 使用 1 张羊毛 | 3/7，当前生命 7，临时生命 +1 | 无 | 3/6，当前生命 6 |
| 3/6 北极熊，当前生命 4 | 使用 1 张羊毛 | 3/7，当前生命 5，临时生命 +1 | 无 | 3/6，当前生命 5 |
| 3/6 北极熊，当前生命 4 | 使用 2 张羊毛 | 3/8，当前生命 6，临时生命 +2 | 受到 3 点伤害，当前生命变为 3 | 3/6，当前生命仍为 3 |
| 3/6 北极熊，当前生命 6 | 使用 2 张羊毛 | 3/8，当前生命 8，临时生命 +2 | 受到 1 点伤害，当前生命变为 7 | 3/6，当前生命夹为 6 |
| 英雄生命 15 | 部署北极熊 | 先公开 3/6，再永久变为 4/6 | 英雄恢复到 20 | 北极熊仍为 4/6 |
| 英雄生命 16 | 部署北极熊 | 保持 3/6 | 英雄之后降到 15 | 北极熊仍为 3/6 |

表中的 `攻击/最大生命` 与“当前生命”分开描述，避免把受伤单位误读为新的基础身材。

## 5. 状态与协议约束

RULE-030C 应新增以下权威字段，并在快照、事件、服务端状态、Unity DTO 和回放仓库中保持同构：

- `temporaryHealthModifier: integer >= 0`
- `temporaryHealthModifierExpiresOnTurn: integer >= 0`

不变量：两个字段同时为零或同时非零；非零修正只允许正值；对象的基础可用生命上限 `maxHealth - temporaryHealthModifier` 必须至少为 1。羊毛还需要把 `TEMPORARY_HEALTH_MODIFIER` 加入属性事件的合法原因集合。旧客户端不得静默忽略新增字段，因此该基础设施必须升级协议版本。

## 6. Unity 交互与表现边界

- 选择羊毛后只高亮合法己方生物的 3D 地表格和模型轮廓；建筑格、敌方单位及空格不得显示为合法目标。
- 点击非法对象保持目标选择状态并显示原因，不消费卡牌；右键、取消键或再次点击已选手牌可退出选择。
- Unity 只在权威事件或离线同构规则接受命令后播放羊毛附着与生命跳字，不得在发命令时预测性改写对局状态。
- 北极熊使用现有 Minecraft 原版模型。永久攻击与临时生命应在世界标签和卡牌详情中有不同标记，不能仅靠相同颜色的数值变化表达。

## 7. 验收矩阵

- 北极熊分别在英雄生命 15 与 16 时部署，边界结果正确；后续治疗和受伤不改变既有结果。
- 北极熊的 `CARD_DEPLOYED → 入场监听 → OBJECT_STATS_CHANGED` 顺序稳定，未触发时没有空事件。
- 羊毛能作用于满生命与受伤的己方生物，且同时提高当前生命与最大生命。
- 两张羊毛可叠加并在施放者结束阶段一次性精确清除；受伤后的当前生命按表中规则保留或夹取。
- 所有非法目标均在付款前原子拒绝；0 费牌不会绕过手牌、阶段或目标验证。
- 快照恢复与事件回放得到相同的临时生命、最大生命和过期回合；旧协议客户端明确拒绝新快照。
- 服务端、Unity 本地 Demo、Unity 权威回放和真实双客户端联机按相同事件顺序与数值收敛。
