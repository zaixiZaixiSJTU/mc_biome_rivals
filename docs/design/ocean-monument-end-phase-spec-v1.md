# 海底神殿结束阶段规范 v1

本规范对应 `protocolVersion 21`、`rulesetVersion prototype-0.30` 与内容版本 22。

## OR-008 海底神殿

- 海底神殿是 `7` 费、`11` 生命、连续占用全部 `3` 个建筑格的传说结构。
- 控制者结束阶段开始时，对每个没有左右相邻存活友方生物的敌方生物造成 `1` 点伤害。只检查同一玩家的 `4` 个单位格；建筑格、跨阵营单位和屏幕距离均不参与相邻判断。
- 位于单位格 `0` 或 `3` 的生物只有一个可能的相邻格。唯一相邻格为空时属于孤立；任一相邻单位格存在存活友方生物时受到保护。
- 伤害不作用于敌方英雄、建筑或结构。

## 多神殿与结算顺序

- 结束回合命令先结算海底神殿，再移除缓慢与“本回合”临时属性，最后发送 `TURN_ENDED`。
- 多个神殿按起始建筑格、实例 ID 的稳定顺序分别触发。每个神殿触发时重新读取当前战场并按单位格、实例 ID 确定孤立目标。
- 同一神殿对所有目标先按稳定顺序各造成 `1` 点伤害，再进入统一死亡批次。死亡、掉落、亡语及其连锁全部完成后，下一座仍存活的神殿才重新计算目标。
- 若某座神殿在更早的死亡连锁中离场，则跳过其尚未发生的触发。
- 神殿伤害造成的击杀归功于神殿控制者，因此敌方掉落按既有规则进入控制者手牌或弃牌堆。

## 权威事件

- 每个受伤单位产生一个 `OBJECT_STATS_CHANGED`，字段为：`sourceCardId = or_008`、真实 `sourceInstanceId`、`effectId = effect.or_008.01`、`reason = DAMAGE` 以及最终攻击/生命和临时攻击字段。
- 死亡沿用 `OBJECT_DIED`、`OBJECT_SUMMONED`、`CARD_GENERATED` 等既有事件，不新增客户端推测字段。
- 本效果没有跨回合私有状态，因此保持 `protocolVersion 21`；规则集升级用于阻止旧结算顺序客户端静默加入。

## Unity 交互与表现

- 当任一玩家即将结束自己的行动回合且控制存活海底神殿时，所有将受伤的敌方单位地块显示低强度琥珀红贴地脉冲，并在铭牌显示`神殿锁定`。可攻击、悬停、按压与非法反馈继续拥有更高优先级。
- 控制者进入战斗阶段后，主按钮显示预计受影响的单位数量，例如`结束回合 · 神殿 2`。
- 结算时先脉冲来源结构，再依次脉冲受伤单位；伤害后的生命和死亡必须来自权威事件。
- 海底神殿模型必须横跨三个建筑地块，使用海晶石、暗海晶石与海晶灯材质构成可辨识的 Minecraft 式阶梯神殿，而不是把单格建筑模型横向拉伸。
