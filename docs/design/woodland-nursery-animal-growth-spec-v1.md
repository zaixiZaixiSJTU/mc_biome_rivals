# 林地苗圃动物成长规范 v1

本规范对应 `protocolVersion 21`、`rulesetVersion prototype-0.31` 与内容版本 23。

## PF-005 林地苗圃

- 林地苗圃是 `2` 费、`4` 生命、占用 `1` 个建筑格的植物 / 生产建筑。
- 每个林地苗圃独立监听其控制者在一个行动回合内第一次进入单位格的动物生物。触发后，该生物永久获得 `+0/+1`，当前生命与最大生命同时增加 `1`。
- 正常部署与效果召唤都属于“进入单位格”；移动、控制权变化和从其他区域返回手牌不属于召唤。
- 林地苗圃自身是建筑，不会触发自身效果。一个动物入场时，所有本回合尚未触发且仍存活的己方林地苗圃按建筑格、实例 ID 的稳定顺序分别触发，因此可以叠加。
- 新部署的林地苗圃只监听其部署之后的动物，不追溯本回合早先的召唤；离场后已经给予的永久生命不移除。

## 权威状态与事件顺序

- 复用玩家状态中的 `triggeredEffectKeysThisTurn`，键格式为 `<nurseryInstanceId>:effect.pf_005.01`。任一玩家结束行动回合时，双方的本回合触发键按既有规则统一清空。
- 动物单位部署的事件顺序为：`CARD_DEPLOYED` → 海龟相邻光环重算 → 林地苗圃成长 → 珊瑚礁成长 → 该单位自身战吼或移动选择。
- 效果召唤的事件顺序为：`OBJECT_SUMMONED` → 海龟相邻光环重算 → 林地苗圃成长 → 珊瑚礁成长 → 后续死亡批次检查。
- 每个林地苗圃触发一次 `OBJECT_STATS_CHANGED`：`reason = PERMANENT_HEALTH_MODIFIER`，并携带来源卡、来源实例、最终 `health`、最终 `maxHealth` 与现有临时攻击字段。
- 同一生物同时具有动物与水生标签时，林地苗圃事件先于珊瑚礁事件，分别保留来源与最终数值，保证回放顺序稳定。
- 客户端只能根据权威事件和快照更新永久生命与触发状态，不得因动画提前修改对局状态。

## Unity 表现

- 林地苗圃使用橡木、树叶和苗圃花床构成专属体素建筑，不使用通用双塔占位模型。
- 未触发的苗圃建筑地块显示低强度叶绿色贴地材质脉冲；已经触发后降为中性占用状态。悬停、可操作和攻击目标高亮仍具有更高优先级。
- 建筑实体标签明确显示“苗圃培育：待触发”或“苗圃培育：本回合已触发”。
- 成长结算时，来源苗圃与目标动物依次播放脉冲，状态栏和像素横幅明确显示永久生命成长。
- 专用预览同时展示苗圃模型、获得成长的 Minecraft 动物模型、最终生命和本回合触发状态。

## 验收

- 第一只己方动物入场获得永久 `+0/+1`，第二只同回合动物不会再次触发同一苗圃。
- 多个苗圃按稳定顺序叠加；回合切换后分别重新就绪。
- 非动物、敌方动物和移动中的动物不会消耗触发。
- 权威服务端、Unity 本地规则、在线事件表现和专用运行预览一致。
