# ED-007 末影水晶结束阶段与亡语规范 v1

本规范对应 `protocolVersion 30`、`rulesetVersion prototype-0.47` 与内容版本 39。

## 权威规则

- 末影水晶是费用 4、4 点生命、占用 1 个建筑格的末地建筑。
- 其控制者结束阶段，每座存活的末影水晶对敌方英雄造成 2 点普通伤害；普通伤害先消耗护甲，剩余部分再减少生命。
- 末影水晶死亡后，对其拥有者英雄造成 2 点真实伤害；真实伤害无视护甲。
- 多座末影水晶按建筑格、实例 ID 的稳定顺序逐座触发。任一脉冲造成致命伤害后立即结束对局，不再触发后续水晶，也不发布 `TURN_ENDED`、下一回合开始或抽牌事件。
- 末影水晶亡语属于死亡批次的一部分。对象先发布 `OBJECT_DIED` 并离开战场，随后发布反噬伤害；若反噬致命，立即发布 `MATCH_ENDED(reason=SELF_DAMAGE)`，并停止该批次其余亡语与掉落。

## 结束阶段顺序

当前固定顺序为：海底神殿 → 生物状态（如中毒）→ 玩家状态持续时间 → 末影水晶 → 洞穴结构产出/召唤 → 临时攻击恢复 → `TURN_ENDED`。

这一顺序由服务端权威执行，离线 Demo 使用同一顺序。完整的“同一控制者手动排列同时触发效果”仍属于后续通用系统；在该系统落地前不得由客户端自行重排。

## 协议与回放

- 结束阶段与亡语都复用 `HERO_DAMAGED`：`damageType=NORMAL` 表示结束阶段脉冲，`damageType=TRUE` 表示亡语反噬。
- 协议 30 为 `HERO_DAMAGED.payload` 增加可选 `sourceInstanceId`。来自持续战场对象的伤害必须提供该字段；无战场实例的法术、疲劳与出土效果可继续省略。
- 客户端仍只根据事件中的最终 `life` 与 `armor` 回放，不在本地重新计算护甲吸收。
- 致命亡语会清除待处理选择并锁定后续命令；事件批次必须只包含终局前已经结算的效果。

## Unity 表现

- 水晶使用黑曜石基座、紫珀台座、悬浮晶核和十二根像素梁构成的线框笼体，模型直接位于 3D 建筑格中并继承战场相机透视。
- 当轮到水晶控制者行动且效果尚可在本回合结束阶段触发时，所在建筑格显示低强度末地紫材质脉冲。
- 普通脉冲显示“末影脉冲”，强调来源水晶与受伤英雄；亡语显示红紫色“水晶反噬”，即使来源对象已经离场也必须保留英雄受击反馈。
