# 小麦友方目标效果规范 v1

本规范对应 `protocolVersion 26`、`rulesetVersion prototype-0.40` 与内容版本 32。

## TK-002 小麦

- 小麦是 `0` 费材料牌，必须指定一个存活的己方生物。
- 在扣费和移入弃牌堆之前，权威规则必须验证目标类型、控制权与稳定实例 ID；敌方生物、建筑、结构和不存在的实例均为非法目标。
- 合法结算先为目标恢复 1 点生命，不能超过最大生命，并发送 `reason = HEAL` 的 `OBJECT_STATS_CHANGED`。
- 若目标具有 `animal` 标签，再获得本行动回合 +1 攻击，并发送独立的 `reason = TEMPORARY_ATTACK_MODIFIER` 事件。
- 动物增攻与雪球、骨头等临时攻击修正共用同一累计字段，在当前行动者结束回合时统一、精确移除。
- 非动物目标仍可合法获得治疗，但不会产生临时攻击事件。

## Unity 交互与表现

- 选中小麦后，右侧主按钮显示“选择喂食目标”；进入目标态后只高亮己方单位格的贴地材质，不创建屏幕空间方框。
- 操作提示明确说明动物会额外获得本回合 +1 攻击，取消方式继续使用右键或 Esc。
- 权威 `CARD_PLAYED` 到达时显示“喂食”横幅；后续属性事件刷新世界铭牌并脉冲目标实体。
- 村民农夫预览同时放置受伤绵羊和农夫，并让生成的小麦进入目标选择态，以便目视验证完整资源链。

## 验收

- 服务端和 Unity 本地规则对受伤动物产生“治疗后增攻”，结束回合后只移除临时攻击。
- 对非动物只治疗，不错误增加攻击。
- 失败的目标校验必须保持手牌、红石、弃牌堆和 revision 不变。
- 事件批次符合共享 JSON Schema，目标对象通过稳定实例 ID 更新。
