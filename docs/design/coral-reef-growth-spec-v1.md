# 珊瑚礁水生成长规范 v1

本规范对应 `protocolVersion 22`、`rulesetVersion prototype-0.32` 与内容版本 24。

## OR-007 珊瑚礁

- 珊瑚礁是 `3` 费、`5` 生命、占用 `1` 个建筑格的水生生产建筑。
- 每个珊瑚礁独立监听其控制者在一个行动回合内第一次进入单位格的水生生物。触发后，该生物永久获得 `+0/+1`，当前生命与最大生命同时增加 `1`。
- 正常部署与效果召唤都属于“进入单位格”；移动、控制权变化和从其他区域返回手牌不属于召唤。
- 珊瑚礁自身是建筑，不会触发自身效果。一个水生生物入场时，所有本回合尚未触发且仍存活的己方珊瑚礁按建筑格、实例 ID 的稳定顺序分别触发，因此可以叠加。
- 新部署的珊瑚礁只监听其部署之后的水生生物，不追溯本回合早先的召唤。珊瑚礁离场后，其已经给予的永久生命不移除。

## 权威状态与事件顺序

- 复用玩家状态中的 `triggeredEffectKeysThisTurn`，键格式为 `<coralInstanceId>:effect.or_007.01`。任一玩家结束行动回合时，双方的本回合触发键按既有规则统一清空。
- 水生单位部署的事件顺序为：`CARD_DEPLOYED` → 海龟相邻光环重算 → 珊瑚礁成长 → 该单位自身战吼或移动选择。
- 效果召唤的事件顺序为：`OBJECT_SUMMONED` → 海龟相邻光环重算 → 珊瑚礁成长 → 后续死亡批次检查。
- 每个珊瑚礁触发一次 `OBJECT_STATS_CHANGED`：`reason = PERMANENT_HEALTH_MODIFIER`，并携带来源卡、来源实例、最终 `health`、最终 `maxHealth` 与现有临时攻击字段。
- 客户端只能根据权威事件和快照更新永久生命与触发状态，不得因动画提前修改对局状态。

## Unity 表现

- 未触发的珊瑚礁所在建筑地块显示低强度珊瑚色贴地材质脉冲；已经触发后降为中性占用状态。悬停、可操作和攻击目标高亮仍具有更高优先级。
- 建筑实体标签明确显示“珊瑚滋养：待触发”或“珊瑚滋养：本回合已触发”。
- 成长结算时，目标单位播放海晶色生命脉冲并显示最终生命值；多个珊瑚礁叠加时可以连续播放，但不得合并或重排权威事件。
- 预览必须同时展示珊瑚礁建筑格、水生单位获得永久生命以及本回合触发状态，避免只展示卡面而看不出建筑的持续作用。
