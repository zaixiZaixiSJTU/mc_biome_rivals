# 冰刺之巅边缘召唤规则 v1

本规范对应 `protocolVersion 28`、`rulesetVersion prototype-0.44` 与内容版本 36，覆盖 SI-008「冰刺之巅」。

## 触发定义

- 只监听 `OBJECT_SUMMONED` 对应的规则召唤；从手牌使用 `DEPLOY_CARD` 部署的单位不触发。
- 每次召唤独立读取召唤发生前目标单位排的四个槽位。
- 在当次召唤前所有空槽中，索引最小者是“当前最左空格”，索引最大者是“当前最右空格”。两者可能是同一个槽。
- 最终召唤槽等于任一边界时，敌方存活的冰刺之巅施加一层非叠加缓慢；否则不触发。
- 亡语等带优先回填槽的召唤仍使用同一判定。例如整排为空时回填单位格 2（索引 1）属于内部格，不触发。

## 状态与时序

- 冰刺缓慢使用已有 `SLOW` 状态，持续 1 个目标控制者结束阶段，不修改攻击数值，但禁止普通攻击。
- 事件顺序为 `OBJECT_SUMMONED` → 己方入场成长监听 → `OBJECT_STATUS_APPLIED`。
- 若多个冰刺之巅同时存在，按起始建筑格和稳定实例 ID 选择第一个来源，避免为同一个非叠加状态制造重复事件。
- 结束阶段开始时先结算当时已经存在的状态，再处理林地府邸等结束阶段召唤。因此该阶段新兵获得的缓慢会保留到其控制者下一次结束阶段。

## 表现与验证

- 冰刺结构的两个占用地块使用同相位冰蓝材质脉冲，不添加 UGUI 悬浮框。
- 受影响单位沿用缓慢的 3D 地表高亮和世界铭牌；联机事件额外显示“冰刺封锁”横幅并脉冲来源结构。
- 服务端测试覆盖连续边缘召唤、部署排除、内部亡语回填和结束阶段新状态；Unity 测试覆盖双方触发、本地排除、跨格模型以及材质颜色。
