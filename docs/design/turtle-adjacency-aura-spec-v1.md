# 海龟相邻生命光环规范 v1

本规范对应 `protocolVersion 22`、`rulesetVersion prototype-0.32` 与内容版本 24。

## OR-005 海龟

- 海龟是 `4` 费 `3/6` 水生动物，并保留公开关键词`嘲讽`。
- 每个存活海龟为左右相邻单位格中的其他己方生物提供 `+0/+1`。光环不作用于来源自身；相邻的多只海龟分别生效并可以叠加。
- 光环是由当前站位实时推导的连续状态，不是永久战吼。单位部署、召唤、移动或死亡导致相邻关系改变时，服务端必须立即重算。
- 获得一层光环时，`maxHealth` 与当前 `health` 同时增加 1；失去一层时两者同时减少 1。若失去光环使当前生命降到 0，立即进入统一死亡结算。
- 权威状态保存 `adjacencyHealthModifier`，其值必须等于当前相邻且效果已实现的友方海龟数量。客户端不得根据画面位置自行猜测数值。

## 事件与结算顺序

- 光环变化使用 `OBJECT_STATS_CHANGED`，`reason = AURA_RECALCULATED`，并携带最终 `health`、`maxHealth` 与 `adjacencyHealthModifier`。
- 部署或召唤顺序：对象公开进入战场，然后重算光环，再继续处理该对象的战吼或后续效果。
- 移动顺序：`OBJECT_MOVED` 后立即重算光环并结算因光环丢失产生的死亡；移动单位仍存活时，才继续结算水流/海晶碎片、海豚向导与守卫者反应。
- 死亡顺序：同批死亡对象先离场，随后重算剩余单位的光环，再按既有顺序处理亡语与掉落；新产生的死亡进入下一批。

## Unity 表现

- 受光环影响的单位标签显示`海龟光环 +N生命`，生命值使用权威快照或事件中的最终值。
- 海龟左右相邻的地表单位格保持低强度海晶色材质发光；可操作目标、悬停和按压高亮仍拥有更高优先级。
- 光环获得、失去时脉冲受影响的 3D 单位并显示短暂`潮甲光环`横幅，不增加悬浮 2D 网格。
- 海龟预览应同时展示嘲讽、相邻生命加成和移动后可能失去光环的站位含义。
