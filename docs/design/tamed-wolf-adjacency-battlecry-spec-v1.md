# 驯服的狼相邻战吼规范 v1

本规范对应 `protocolVersion 21`、`rulesetVersion prototype-0.29` 与内容版本 21。

## PF-003 驯服的狼

- 驯服的狼是 `2` 费 `3/2` 动物生物。
- 战吼在本牌成功进入指定单位格后检查一次：若其左侧或右侧相邻单位格存在另一个存活的己方“动物”生物，本牌永久获得 `+0/+1`；当前生命与最大生命同时增加 `1`。
- 两侧都存在动物时仍只触发一次。驯服的狼自身虽然具有动物标签，但不参与自己的条件。
- 只检查同一单位排中索引差恰好为 `1` 的地块；空格、建筑格、敌方生物、非动物生物及已经死亡但尚待清理的对象均不满足条件。
- 战吼只看落位瞬间。动物邻居后来移动或死亡不会移除已获得的生命，动物后来移动到相邻格也不会补触发。

## 结算与事件顺序

- 部署顺序为付款与占格 → `CARD_DEPLOYED` → 动态相邻光环重算 → 已有入场监听 → 驯服的狼战吼。
- 战吼成功时发送一个 `OBJECT_STATS_CHANGED`：`sourceCardId = pf_003`、`sourceInstanceId =` 本牌实例、`effectId = effect.pf_003.01`、`reason = PERMANENT_HEALTH_MODIFIER`，并携带最终攻击、当前生命、最大生命与已有临时攻击字段。
- 战吼不成功时不发送属性事件，也不创建隐藏的触发标记。
- 若本牌同时受到动态生命光环，事件中的最终最大生命包含光环；光环日后移除时，本战吼提供的永久 `+1` 仍保留。
- 本效果没有新增消息字段，保持 `protocolVersion 21`；规则集版本用于阻止旧战吼顺序客户端静默加入。

## Unity 交互与表现

- 选中驯服的狼时，合法且相邻存活动物的空单位格使用金色贴地材质脉冲，普通合法格继续使用青绿色；悬停文案必须明确该位置是否会触发战吼。
- 战吼事件播放来源单位脉冲和“忠诚成长”短横幅。战场铭牌在永久生命已生效时显示`忠诚 +1生命`。
- 表现只读取当前权威快照和事件，不在客户端预测或修改最终属性。
- 专用预览同时展示动物邻居、已经获得永久生命的狼，以及仍可触发战吼的金色部署地块。

## 验收

- 有左邻或右邻动物时从 `3/2` 变为 `3/3`，属性事件紧随部署事件。
- 两侧动物仍只获得 `+1` 最大生命；非动物、隔一个空格和敌方动物均不触发。
- Unity 本地规则与 Nakama 权威规则结果一致，快照重建后最终生命不丢失。
- 交互高亮来自 3D 地表材质，并继续服从相机透视、悬停和按压优先级。
