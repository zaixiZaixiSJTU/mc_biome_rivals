# 山羊越位战吼规范 v1

本规范对应 `protocolVersion 28`、`rulesetVersion prototype-0.45` 与内容版本 37，覆盖 SI-004「山羊」。

## 规则定义

- 战吼为可选效果。玩家可以不提供目标，直接把山羊部署到任意合法空单位格；此时不移动单位，也不获得攻击加成。
- 若选择目标，目标必须是一个存活的己方生物，并与山羊的部署格相邻。
- 目的格以部署格为轴确定：`目的格 = 2 × 山羊部署格 - 目标当前格`。目的格必须位于同一条 4 格单位排内，且在命令结算前为空。
- 目标、部署格、目的格、费用与手牌归属统一在支付前校验。任一条件不满足时整条命令原子拒绝，不扣红石、不移除手牌、不改变战场。
- 目的格由已提交的目标与部署格唯一确定，因此不产生 `CHOICE_OFFERED`，避免一次战吼拆成两个可过期的网络选择。

## 结算顺序

1. 山羊正常部署并发出 `CARD_DEPLOYED`。
2. 目标跨过山羊进入目的格并发出 `OBJECT_MOVED(effect.si_004.01)`。
3. 重算相邻生命光环并结算由失去光环导致的死亡。
4. 若移动单位仍存活，进入通用成功移动反应链：海豚向导先结算，敌方守卫者随后结算，均沿用各自每回合一次限制。
5. 只要山羊仍在场，它获得本回合 +1 攻击并发出 `OBJECT_STATS_CHANGED`；该加成在控制者结束阶段移除。

移动单位即使在守卫者反应中死亡，已经发生的移动仍视为成功，山羊仍可获得攻击加成。若山羊因前置的相邻光环重算离场，则不再获得加成。

## 客户端交互

- 右侧详情面板提供“选择冲撞友军（可选）”；没有合法目标时按钮禁用，但普通部署保持可用。
- 锁定目标后，仅满足三格直线路径的中间部署格显示为金色地表高亮；其他空格在点击前即显示为非法。
- 玩家可取消已锁定目标，回到无目标的普通部署方式。
- 本地对局和联机对局使用同一 `targetType=UNIT + targetInstanceId` 命令结构；位置变化只来自规则状态刷新，不由卡面或动画直接改写。

## 验证覆盖

- 服务端覆盖成功越位、跳过战吼、阻塞路径原子拒绝、临时攻击到期、海豚/守卫者顺序以及事件 Schema。
- Unity EditMode 覆盖同构本地规则、合法目标判断、阻塞路径、反应链、MC 山羊纹理键与带角实体网格。
