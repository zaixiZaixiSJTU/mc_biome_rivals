# 村民农夫小麦战吼规范 v1

本规范已按当前组合校准为 `protocolVersion 28`、`rulesetVersion prototype-0.44` 与内容版本 36。

## PF-004 村民农夫

- 村民农夫是 `3` 费 `2/4` 村民 / 交易生物。
- 成功部署后，战吼将一张已注册材料牌 `TK-002 小麦` 生成给控制者。
- 农夫先从手牌移除并完成占格、付款和 `CARD_DEPLOYED`，随后才生成小麦并发送 `CARD_GENERATED`。
- 小麦生成至手牌时，事件包含来源卡、来源实例、`effect.pf_004.01`、`destination = HAND`、最终手牌数与弃牌数。
- 生成到手牌的卡牌身份只投影给拥有者；对手只知道农夫生成了一张牌，`cardId` 必须为 `null`。

## 手牌上限

- 手牌上限仍为 `7`。合法部署要求农夫原本位于手牌，因此即使部署前有 7 张牌，农夫离手后也会先腾出一个位置，小麦生成后手牌精确回到 7 张。
- 通用生成器继续保留“手牌已满则进入公开弃牌堆”的安全兜底，但在当前无中间生成触发器的 PF-004 部署顺序中，该分支不可达，不为测试伪造非法的 8 张起始手牌。
- 若部署因红石、阶段、格位或版本校验失败，不得移除农夫、生成小麦或发送任何事件。

## Unity 表现

- 权威 `CARD_GENERATED` 到达时，拥有者显示“村民农夫战吼：小麦已置入你的手牌”，播放“收获小麦”横幅和玩家手牌/HUD 金色脉冲。
- 对手只显示“敌方村民农夫战吼：对手获得一张牌”，不得通过卡图、名称、日志或动画泄露小麦身份。
- 小麦进入目标选择态后，只高亮己方存活生物所在的真实 3D 地表；结算时为目标恢复 1 点生命，目标具有“动物”标签时再获得本回合 +1 攻击力。
- 本地演示遵循相同的 7 张手牌边界和文案。专用预览同时展示 Minecraft 村民与绵羊模型、手牌中的小麦卡、右侧小麦详情及合法己方目标高亮。
- 卡面、手牌和详情继续复用同一 `CardUI` 结构，不为生成牌创建独立矢量样式。

## 验收

- 普通部署产生严格顺序 `CARD_DEPLOYED → CARD_GENERATED`，小麦进入拥有者手牌。
- 7 张手牌部署后仍为 7 张：农夫消失，小麦出现，弃牌数不变。
- 对手事件投影隐藏生成牌身份，快照也只保留未知手牌占位。
- 生成的小麦可指定己方生物；动物与非动物分支、临时攻击恢复时点均由权威规则测试覆盖。
- Unity 本地规则、权威规则、预览与在线事件反馈一致。
