## 1. 冻结后的规则文本

| ID | 属性 | 冻结后的规则文本 |

| ED-003 末影人 | 3 费，4/3，生物 | **战吼：**可以悬置另一个己方生物。若成功悬置，本牌获得 +0/+1。 |
| ED-005 末影珍珠 | 2 费，法术 | 选择一个己方生物，将其移回拥有者手牌；该次进入手牌的牌本回合费用减少 2，最低为 0。 |
| ED-006 虚空凝视 | 3 费，法术 | 悬置一个敌方生物。 |

“悬置”的固定含义为：将战场生物正面移入公开除外区；在其拥有者的下一个起始阶段返回拥有者手牌，并仅对这次返回产生的精确手牌实例施加本回合 `-1` 费用，最低为 0。悬置不是死亡、弃置或普通回手。

## 2. 必须先建立稳定的手牌实例

### 2.1 禁止用同名卡 ID 代替实例身份

当前运行时以 `string[] hand` 和 `hand.indexOf(cardId)` 处理手牌。同名卡存在时，这无法回答玩家点击的是哪一张，也无法保证折扣、支付、重连和回放作用于同一副本。后续实现必须先满足：

1. 权威手牌中的每张牌都有稳定且唯一的 `handCardInstanceId`，至少包含 `cardId`、当前手牌费用修正及其到期归属。抽取、生成、起手替换、出土、掉落、回手和悬置返回进入手牌时都分配新实例。
2. `DEPLOY_CARD` 与 `PLAY_CARD` 必须以 `handCardInstanceId` 精确选择副本；`cardId` 只能作为被服务端核验的一致性字段，不能继续决定“第一张同名卡”。合成产物与材料消耗也必须排除/选择确定的手牌实例。
3. 自己的快照包含完整手牌实例和有效费用；对手快照仍只暴露等量空占位，不泄露 `cardId`、实例 ID 或费用修正。公开移动事件可以携带刚从战场公开区域进入手牌的卡名，但不能因此公开其他手牌。
4. `handCardInstanceId` 只标识一次连续的手牌停留。牌离开手牌后该实例终止；以后重新进入手牌时分配新实例，旧费用修正不能跨战场、弃牌堆或除外区残留。
5. Unity 手牌选择、卡牌详情、可支付判断和命令生成必须使用实例 ID。两张同名卡可以同时显示不同费用，点击折扣副本不能误发另一张。

RULE-033 不要求把隐藏牌库和弃牌堆整体改造成对象数组；牌库仍可保存卡牌 ID，但每次进入手牌必须形成实例。不得使用“卡牌 ID → 单个折扣值”的映射，因为它会错误影响所有同名牌。

### 2.2 费用修正与到期

- 即时回手的修正为 ED-002 的 `-1` 或 ED-005 的 `-2`；悬置返回固定为 `-1`。有效红石费用为 `max(0, 基础费用 + 当前手牌实例修正 + 其他实时修正)`。
- DB-005 等玩家级实时修正与精确手牌修正相加后统一在 0 截断。合成配方和材料数量不因红石费用修正改变；选择 `CRAFTING` 支付时不消费或折算红石减费。
- “本回合”按当前行动玩家的当前回合解释。手牌实例必须保存 `expiresAtEndOfTurnPlayerId`；轮到该玩家结束回合时清除所有匹配修正并发布权威到期事件。若未来回手一个由他人拥有的受控对象，牌仍回到拥有者手牌，但折扣会在**当前行动玩家**结束回合时到期，不能擅自延长到拥有者下次行动。
- 修正只存在于手牌。打出、弃置、消耗或再次离开手牌时立即随实例消失；同一物理卡以后再次回手只获得新效果明确授予的新修正，不继承旧值。
- 当前五张牌不会让多个回手修正同时附着到同一手牌实例；基础设施仍应以整数修正表示，不将 `-1`/`-2`写死进 UI。

## 3. 所有权、控制权与区域模型

1. 每个战场对象必须保存不可随控制权变化而改变的 `ownerPlayerId`。正常从手牌部署的对象归出牌者；召唤的衍生物归召唤方。对象所在玩家战场仍表示当前控制者。
2. 即时回手和悬置返回都进入**拥有者**区域，不进入离场前控制者区域。当前卡池尚无夺取控制权效果，但模型、事件和测试必须保留这个区别。
3. 公开除外区使用比赛级 `suspendedCards`，而不是藏在某位玩家的私有手牌数据里。每项至少保存：稳定 `suspensionId`、`cardId`、`ownerPlayerId`、离场前 `controllerPlayerId`、来源玩家/卡牌/实例/效果、创建顺序和返回费用修正。
4. 除外区正面公开。双方快照都能看到同一条目、顺序、拥有者和“下个拥有者起始阶段返回”的语义；不能看到拥有者其他手牌。
5. 战场对象离场时，其伤害、状态、已攻击标记、召唤回合、临时/永久属性修正和光环派生值全部随对象实例销毁。回手或悬置返回后只形成基础卡牌的手牌实例；重新部署会创建新的战场实例。

## 4. 即时回手事务

### 4.1 目标与支付前验证

- ED-002、ED-005 都必须选择一个由施放者当前控制、在战场存活的生物。英雄、建筑、结构、敌方生物、已离场或待死亡对象非法；没有合法目标时不能打出。
- 目标合法性、手牌实例、阶段和费用在支付前一次性验证。失败不扣费、不移除来源牌、不移动目标、不推进 revision/实例序列，也不发事件。
- TK-017 只在“来源卡牌类型为 `SPELL` 且来源玩家等于目标当前控制者”时拒绝回手或悬置。ED-005 不能回手己方 TK-017；ED-002 是材料，因此可以。不得把这条文本扩成对所有己方效果或敌方法术的免疫。

### 4.2 结算顺序与满手

合法行动按以下原子顺序结算：

1. 移除所选来源手牌实例并支付费用；材料/法术按现有规则进入弃牌堆，发布 `CARD_PLAYED`。
2. 重新确认锁定目标仍在原控制者战场、存活且仍为生物。若强制监听使其失效，来源牌保持已使用且不退款，不发布伪造的区域移动事件。
3. 从战场和单位格移除目标，销毁对象状态，并按离场后的战场重算光环。此过程不进入死亡检查，不触发亡语或掉落。
4. 若拥有者手牌少于 7，创建精确手牌实例并施加本次折扣；否则按 GDD 回手规则将公开卡牌直接放入拥有者弃牌堆，不创建手牌实例或费用修正。
5. 发布 `OBJECT_RETURNED`，载荷包含目标原实例、卡牌、拥有者、离场前控制者、来源、原格位、`destination = HAND | DISCARD`、新手牌实例（若有）、修正、到期玩家及区域计数。随后处理离场监听与统一胜负检查。

`CARD_PLAYED → OBJECT_RETURNED` 必须保持因果相邻；中间只允许由“来源牌已打出”明确规定的强制监听。典型情况下来源牌先离开手牌，因此 ED-002/005 会先腾出一个手牌位置，但实现仍必须正确处理监听重新填满手牌的情况。

## 5. 悬置事务与起始阶段返回

### 5.1 进入公开除外区

1. 悬置目标必须是战场上的存活生物。悬置不造成伤害，不属于死亡、摧毁、弃置或普通回手，不触发亡语和掉落。
2. 成功时释放单位格、移除战场对象、销毁其所有运行时状态，创建公开 `suspendedCards` 条目并发布 `OBJECT_SUSPENDED`。载荷包含原对象、拥有者/控制者、来源、原格位、`suspensionId` 和返回修正 `-1`。
3. 条目按 `suspensionId` 的数值创建顺序稳定排序。断线重连、服务恢复和 Unity 离线 Demo 必须恢复相同顺序与完整来源。
4. 每个成功的 `OBJECT_SUSPENDED` 都保存造成悬置的 `sourcePlayerId`，供 RULE-034 以后计算“己方本局已悬置”；RULE-033 不提前新增累计计数或 ED-008 奖励。

### 5.2 下个拥有者起始阶段

悬置牌在创建时所在起始阶段已经视为错过。由于当前卡牌只会在主行动阶段创建悬置，实际流程固定为其拥有者**下一次** `TURN_STARTED` 后返回：

1. 重置攻击次数、恢复红石并发布 `TURN_STARTED`。
2. 在普通抽牌和其他尚未实现的卡牌式回合开始触发之前，取出该拥有者全部悬置条目，按 `suspensionId` 升序逐张处理。
3. 每张若手牌未满，创建新手牌实例并施加 `-1`，到期玩家为当前起始阶段玩家；若手牌已满，则正面进入拥有者弃牌堆。无论目的地为何，该条目都从除外区移除，不会继续等待下一回合。
4. 每张发布 `SUSPENDED_CARD_RETURNED`，包含 `destination`、新手牌实例/费用（若有）、原悬置来源、手牌/弃牌/除外区计数。全部返回完成后才执行普通抽牌，因此返回可能占满手牌并使本回合抽牌爆牌。
5. 每张区域移动后处理强制监听和胜负检查；比赛一旦结束，停止其余返回和抽牌，不在 `MATCH_ENDED` 后发布事件。

若未来出现“起始阶段中悬置”效果，它发生在本段返回窗口之后，因此等到该拥有者再下一个起始阶段；实现不得在遍历期间把新条目重新收入同一批。

## 6. 卡牌特定裁决

### 6.1 ED-003 末影人

- 战吼是可选的：即使存在合法目标，也可以不选并正常部署；不选时没有悬置和 +0/+1。
- 选择时目标必须是部署者控制的另一个存活生物。目标从部署前战场集合中锁定，不能选择正在部署的 ED-003 自己。
- 可选目标随部署命令和单位格一起提交，不建立部署后的第二条私有选择。目标非法时整条部署在支付前拒绝；显式不选使用空目标字段，不接受伪实例 ID。
- 权威顺序为 `CARD_DEPLOYED → OBJECT_SUSPENDED → OBJECT_STATS_CHANGED`。只有 `OBJECT_SUSPENDED` 实际成功后，ED-003 才永久增加 1 点当前/最大生命；目标在部署监听中失效时不悬置、不加血、不退款。
- TK-017 可以被 ED-003 悬置，因为来源是生物战吼而非法术。

### 6.2 ED-006 虚空凝视

- 必须选择一个由对手当前控制的存活生物；己方对象、英雄、建筑与结构非法。目标拥有者可以与控制者不同，但返回仍按拥有者处理。
- 来源是敌方法术，因此可以悬置目标控制者的 TK-017；TK-017 只阻止当前控制者自己的法术。
- 顺序为 `CARD_PLAYED → OBJECT_SUSPENDED`。目标失效时按即时回手相同的锁定后失效规则处理，不退款、不创建除外条目。

## 7. 协议、投影与 Unity 交互最低边界

- 服务端是事实源。Unity 不得从动画结束、卡牌文本、手牌空位或回合切换自行移动卡牌或计算折扣；只消费权威快照和事件。
- 新协议至少需要手牌实例、对象拥有者、公开悬置条目和对应事件。服务端 clone、快照、Schema、Nakama 投影、Unity DTO/状态仓库、命令工厂与离线 Demo 必须在各纵向切片同构升级。
- 对手私有手牌仍以空占位投影；公开除外区双方逐字段一致。重连必须恢复精确手牌折扣、到期玩家、悬置顺序、来源和区域计数。
- Unity 目标选择只使用 3D 世界内模型与贴地地表反馈。悬置使用末地紫粒子/短暂缩退进入材质化公开除外区托盘；返回从托盘进入手牌并显示基础费用到有效费用的像素化差值，不得恢复成悬浮 Screen Space 网格框或纯色 Web 面板。
- 费用到期必须由权威事件移除视觉折扣。两张同名卡中只有匹配 `handCardInstanceId` 的卡显示和支付折扣。

| 场景 | 冻结结果 |
|---|---|
| 手牌有两张同名 3 费生物，其中一张由 ED-002 回手 | 只为新进入手牌的实例显示/支付 2 费；原有同名牌仍为 3 费 |
| ED-005 选择己方 TK-017 | 支付前拒绝；不扣费、不弃法术、不移动目标 |

| ED-006 选择敌方 TK-017 | 合法；敌方法术不属于目标的“己方法术” |
| ED-003 有合法目标但玩家不选 | 正常部署为 4/3；不悬置、不加血 |
| ED-003 锁定目标后，部署监听令目标离场 | ED-003 保持部署；不创建悬置条目，也不获得 +0/+1 |

| 双方在 revision 相同处重连 | 双方看到相同公开除外区；拥有者看到自己的精确手牌实例和折扣，对手只看到手牌空占位 |
