# 黑暗玩家状态规则 v1

本规范对应 `protocolVersion 28`、`rulesetVersion prototype-0.45` 与内容版本 37，覆盖 CD-004「幽匿感测体」和 CD-006「回响的黑暗」。

## 规则语义

- `DARK` 是玩家状态，不是战场对象状态；公开快照与事件对双方可见。
- 受影响玩家本回合第一次主动指定敌方战场对象时，只能选择该目标类型、该行、当前基础规则下全部合法候选中的最左或最右对象。
- 单位行和建筑行分别计算边缘；空格不算对象，多格结构只按一个稳定实例参与排序。
- 嘲讽、目标阵营、目标类型、存活、相邻等基础合法性先过滤，再在剩余候选中计算左右边缘。
- 英雄不是战场对象，因此始终不受 `DARK` 限制，指定英雄也不消耗限制。
- 第一次合法指定敌方战场对象后，`hasTargetedEnemyObjectThisTurn` 置为 `true`；本回合后续指定恢复普通规则。拒绝的命令不得消耗该标记或资源。
- 若 `DARK` 在玩家已经指定过敌方战场对象后才施加，本回合不追溯限制；状态仍保留到该玩家结束阶段并正常移除。

## 卡牌触发

- CD-004：每个敌方行动回合，在敌方完成第二张牌的全部结算后，对其施加 1 回合 `DARK`。多座感测体按建筑格与实例 ID 稳定触发，状态不叠加。
- CD-006：结算时对对手施加 1 回合 `DARK`，随后由统一抽牌流程抽 1 张牌；爆牌、疲劳和终局均复用现有规则。
- “出牌数”包含成功部署的单位、建筑、结构，以及成功打出的法术、材料和装备；被拒绝的命令不计数。

## 协议与表现

- 玩家快照公开 `cardsPlayedThisTurn`、`hasTargetedEnemyObjectThisTurn` 与 `statuses`。
- 状态生命周期使用 `PLAYER_STATUS_APPLIED`、`PLAYER_STATUS_TICKED`、`PLAYER_STATUS_REMOVED`；事件来源保留 `sourcePlayerId`、`sourceCardId`、`sourceInstanceId` 与 `effectId`。
- Unity 只依据权威快照预览合法目标：中间对象不发光且不可点击，左右边缘对象使用贴地 3D 材质高亮；服务端仍是最终裁决者。
- 幽匿感测体使用本机 Minecraft JAR 白名单提取的方块纹理构造 3D 方块模型；找不到本地纹理时使用同色体素材质回退，不影响规则运行。

## 验收边界

- 第二张牌恰好触发，第一张和第三张不重复触发。
- 三个敌方单位位于 0、1、3 格时，初始仅 0、3 合法；选中 0 后，1 在同回合恢复合法。
- 存在嘲讽时先取嘲讽候选的左右边缘，非嘲讽与英雄仍按嘲讽规则拒绝。
- 无嘲讽时攻击英雄合法且不消耗对象限制。
- 状态在受影响玩家结束阶段移除，同时清零本回合出牌数与指定标记。
