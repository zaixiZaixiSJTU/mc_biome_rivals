# CD-002 洞穴蜘蛛：中毒状态规范 v1

本规范对应 `protocolVersion 28`、`rulesetVersion prototype-0.42` 与内容版本 34。

## 规则语义

- 洞穴蜘蛛对敌方生物造成大于 0 的普通攻击伤害后，为仍然存活的受伤生物施加 `POISON`。
- 普通攻击和生物反击分别独立检查，因此洞穴蜘蛛作为攻击者或防守者都能触发。洞穴蜘蛛即使在同次战斗中死亡，已经造成的伤害仍会触发中毒。
- 建筑、结构与英雄不是合法的中毒对象；被战斗伤害直接消灭的生物不会保留无意义的状态。
- 中毒持续 3 次目标控制者的结束阶段。每次先对目标造成 1 点普通伤害，再将剩余时长减 1；时长归零后移除。
- 同名状态不叠加。再次施加时将剩余时长刷新到 `max(当前值, 3)`；只有实际延长时才替换伤害来源。
- 毒伤保存来源玩家、卡牌、实例与效果 ID。毒伤致死时，击杀归属于来源玩家，可正确触发敌方击杀掉落。
- 对象离开战场时状态随对象清除。多个结束阶段状态暂按状态数组的稳定顺序结算；需要玩家手动排序的完整交互留待后续统一实现。

## 权威事件顺序

战斗施毒：

1. `ATTACK_RESOLVED`
2. `OBJECT_STATUS_APPLIED`
3. 双方死亡结算与其连锁事件

非致死毒伤：

1. `OBJECT_STATS_CHANGED`，`reason = DAMAGE`、`damageType = NORMAL`
2. `OBJECT_STATUS_TICKED`，发布可回放的最新 `remainingDuration`

第三次非致死毒伤改为在伤害事件后发送 `OBJECT_STATUS_REMOVED`；致死毒伤直接进入 `OBJECT_DIED` 与死亡连锁，不再发送状态计时或移除事件。

## 客户端表现

- 状态标签显示“中毒 N”，可与“缓慢 N”等其他状态同时存在。
- 中毒目标脚下直接使用受相机 MVP 变换的 3D 地表材质高亮，以饱和像素绿脉冲显示；不创建 Screen Space 网格框。
- 洞穴蜘蛛使用本机 Minecraft Java JAR 中 `entity/spider/cave_spider.png`，由分件方块模型构造头、胸、腹与八条腿。提取物继续位于 Git 忽略目录。

[查看 1920×1080 确定性运行预览](assets/demo-cave-spider-poison-preview-v1.png)。

## 验收矩阵

- 主动攻击与反击均能施毒，且死亡的受击目标不保留状态。
- 三次控制者结束阶段依次造成 1 点普通伤害，并发布 3→2→1→移除的可回放状态变化。
- 同名状态只有一个实例，刷新不叠层。
- 毒伤击杀可把敌方掉落交给状态来源控制者。
- 权威服务端、Unity 本地模式、Unity 事件回放、协议 Schema 与联机冒烟使用同一版本组合。
