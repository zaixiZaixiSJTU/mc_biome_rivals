# 《我的世界：群系竞逐》原型卡池 v0.1

> 状态：机制验证稿，不代表最终平衡数值  
> 对应规则：GDD v0.5  
> 规模：7 个阵营 × 8 张可收集牌，共 56 张；另含 18 张衍生牌  
> 日期：2026-08-19

## 1. 数值口径

本卡池用于同时验证费用曲线、七格战场、建筑、结构和七种群系机制，不是七套可以直接构筑 30 张牌的完整牌库。

- 普通生物的初始身材预算约为“攻击力 + 生命值 = 费用 × 2 + 1”；立即生效的战吼、强关键词和持续引擎会占用身材预算。
- 1～3 费承担节奏和机制教学，4～6 费承担体系核心，7 费以上承担终局。
- 建筑不能普通攻击，但占用独立建筑格并能被敌方自由攻击，因此用较高生命值交换延迟收益。
- 多格结构会压缩自己的建筑空间；效果可以明显强于单格建筑，但不能落地后立即无条件翻盘。
- 定向伤害基准暂按：1 费约 2 点、2 费约 3 点、3 费约 4 点；能打英雄、附带状态或属于范围伤害时降低效率。
- 抽 1 张牌按约 1.5～2 点红石能量估值。由于手牌上限只有 7，持续补牌要比一次性补牌更谨慎。
- 本表的常见、稀有、史诗牌沿用同名最多 2 张的构筑限制；传说牌标记为“唯一路线”，同名最多 1 张。
- 《炉石传说》仅用于校准费用、攻击、生命和关键词所占的数值预算；KARDS 仅用于校准部署、站场空间与持续行动价值。本项目不引入 KARDS 的单位行动费。

### 属性写法

| 卡牌类型 | 属性栏写法 |
|---|---|
| 生物 | `攻击/生命` |
| 建筑 | `生命` |
| 结构 | `生命；占格数` |
| 装备 | `攻击加成/耐久` |
| 法术、材料 | `—` |

### 本表采用的阵营机制原型

这些定义只服务于本轮测试，测试后再决定是否写回主 GDD。

| 机制 | 本轮可执行定义 |
|---|---|
| 繁殖 | 卡牌检查两个己方生物是否共享指定生态标签，满足时生成幼体或使亲本成长；不提供阵营常驻按钮。 |
| 掩埋 | 将指定衍生牌洗入己方牌库。抽到掩埋牌时先公开并结算其“出土”效果，再正常抽 1 张牌；因此掩埋牌不占用当次正常抽牌。补抽仍是掩埋牌时重复此流程。 |
| 冻伤 | 通过减攻和施加“缓慢”实现；本轮不新增“冻结”状态。 |
| 深暗 | 施加或利用 GDD v0.5 已定义的“黑暗”玩家状态。 |
| 水流 | 卡牌允许己方单位移动至同一单位排的相邻空格；不消耗普通攻击次数。 |
| 岩浆 | 只由具体卡牌触发；结束阶段自动消耗文本规定数量的剩余红石能量并产生效果。多个岩浆效果由控制者排序，能量不足时后续效果跳过。 |
| 悬置 | 将牌正面移入除外区；其拥有者下个起始阶段将其返回手牌，该牌本回合费用减少 1，最低为 0。生物离场时清除伤害和状态。 |

## 11. 首轮测试重点

| 风险 | 重点观察指标 | 建议调整旋钮 |
|---|---|---|
| 单位格太少导致繁殖、水流失效 | 满单位格回合占比；PF-006/OR-001 卡手率 | 幼体身材、失败补偿、场地单位格数量 |
| 建筑格价值过高或过低 | 建筑平均存活回合；攻击建筑与攻击英雄的选择比例 | 建筑生命 ±1；触发改为每回合首次 |
| 掩埋过慢或形成无限资源 | 掩埋牌平均等待回合；每局额外抽牌数 | 掩埋位置、挖掘查看张数、出土收益 |
| 缓慢造成连续无法行动 | 单一生物连续被缓慢回合数 | SI-006 费用、目标限制、状态免疫窗口 |
| 黑暗几乎无影响 | 黑暗期间被迫改变目标的行动次数 | 感测体触发门槛、黑暗持续时间 |
| 水流只是动画而没有决策 | 每次移动带来的伤害/存活差；主动放弃移动次数 | 移动收益、守卫者惩罚、相邻光环数量 |
| 岩浆等于无代价额外伤害 | 每回合未使用能量；岩浆总伤害 | 每张牌消耗上限、伤害值、触发是否可选 |
| 悬置成为廉价硬解 | 被悬置牌重放率；ED-006 使用后的节奏差 | 返回折扣、法术费用、可选目标费用上限 |
| 三格结构过于极端 | 成功部署率；部署后胜率；平均存活回合 | 费用、生命、触发时机、占格数 |
