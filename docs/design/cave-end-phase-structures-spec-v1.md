# 洞穴结构结束阶段规则 v1

本规范对应 `protocolVersion 28`、`rulesetVersion prototype-0.45` 与内容版本 37，覆盖 CD-007「废弃矿井」和 CD-008「林地府邸」。

## 结算时点与顺序

- 两张牌都只在其控制者的结束阶段触发。
- 当前结束阶段顺序为：海底神殿 → 中毒伤害 → 玩家状态过期 → 洞穴结构 → `TURN_ENDED`。这样由林地府邸召唤的新单位在本阶段新获得的状态不会立即过期。
- 同一玩家的洞穴结构按起始建筑格从左到右排序；起始格相同时按稳定实例 ID 排序。
- 每个来源结算前重新确认其仍存活。一个来源产生的新状态不回溯改变此前已经完成的来源结算。

## 废弃矿井

- 条件使用服务端权威的 `cardsPlayedThisTurn`，只接受严格等于 1；0 张和 2 张以上都不触发。
- 合法部署、法术和材料均计为打出；被拒绝的命令、自动生成、抽牌和自动召唤不计数。
- 触发时生成 TK-010「圆石」。手牌少于 7 张时进入私有手牌；满手时进入公开弃牌堆。
- 使用既有 `CARD_GENERATED`，来源为矿井实例，效果为 `effect.cd_007.01`，不新增协议字段。

## 林地府邸

- 结算时若己方四个单位格存在空位，在最左空位召唤 TK-011「卫道士新兵」。
- 新兵为 2/2 单位，属于真实召唤，会进入既有的入场监听链。
- 单位格全满时不触发、不创建对象，也不消耗 `nextInstanceId`。
- 使用既有 `OBJECT_SUMMONED`，来源为府邸实例，效果为 `effect.cd_008.01`，不新增协议字段。

## 表现与验证

- 满足触发条件时，只对建筑实际占用的 3D 地表材质做呼吸高亮；高亮继承战场相机透视和射线交互。
- 权威事件分别显示“矿井产出”和“府邸增援”，生成牌与召唤物沿用统一卡面、手牌和世界对象组件。
- 服务端测试覆盖严格一张、两张跳过、满手弃牌、最左空位和满场不分配实例；Unity 测试覆盖本地结算、注册状态、跨格模型与卫道士纹理复用。
