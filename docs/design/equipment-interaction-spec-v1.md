# 装备与英雄攻击交互规范 v1

本规范对应 `protocolVersion 17`、`rulesetVersion prototype-0.20` 与内容版本 12。

## 权威状态

- 每名英雄有且只有一个公开装备槽，保存稳定实例 ID、攻击、当前耐久和最大耐久。
- 打出新装备时，旧装备先以 `REPLACED` 原因进入弃牌堆，再创建新装备实例。
- 英雄攻击通过现有 `ATTACK` 命令发送，`attackerInstanceId` 固定为 `HERO`；每回合最多一次。
- 攻击英雄不会受到反击；攻击单位会受到该单位攻击力的同步反击。护甲先吸收反击伤害。
- 每次英雄攻击结算后装备失去 1 点耐久；耐久归零时以 `DURABILITY` 原因进入弃牌堆。

## 激流三叉戟 OR-006

英雄使用激流三叉戟攻击单位后，若目标存活且同排左右相邻位置存在空单位格，服务端生成 `MOVE_UNIT` 选择。可选目标仅包含仍为空且与目标相差一格的位置，`selectedOptionIndex = -1` 表示保持原位。

选择期间除 `RESOLVE_CHOICE` 与 `CONCEDE` 外的命令全部拒绝。选择、目标实例与合法目的地写入双方快照；只有选择拥有者的选项带 `selectable: true`。实际位移通过 `OBJECT_MOVED` 广播，客户端不得自行猜测位置。

## Unity 呈现

- 双方英雄 HUD 旁显示材质化装备牌，包含名称、攻击和耐久。
- 战斗阶段点击己方英雄选中英雄攻击者，再点击敌方单位、建筑或英雄。
- `MOVE_UNIT` 不使用遮挡场景的卡牌弹窗：目标单位使用金色地表强调，合法空格使用战场 3D 高亮材质，直接点击地块提交选择。
- 右侧战斗面板只显示效果说明和“保持原位”按钮。移动完成后由权威快照/事件刷新单位位置。
