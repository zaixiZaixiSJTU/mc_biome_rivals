# 海晶碎片位移规范 v1

本规范对应 `protocolVersion 21`、`rulesetVersion prototype-0.30` 与内容版本 22。

## 合法目标与支付

- `TK-012 海晶碎片`只能在主行动阶段指定一个存活的己方水生单位。
- 目标必须至少拥有一个同排左右相邻的空单位格。水生标签、目标归属、存活状态和相邻空格均在扣除费用、移出手牌前原子校验。
- 合法打出后，海晶碎片进入弃牌堆并创建公开 `MOVE_UNIT` 选择；选择完成前继续锁定其他命令。
- 该移动是材料效果的必要组成部分，不能选择保持原位。若目标或空格在权威状态中不再匹配，整条选择命令拒绝且等待玩家重新选择当前合法选项。

## 来源标识与事件顺序

- 非永久卡牌效果没有场上对象实例，使用稳定的 `effect-<CARD_PLAYED eventId>` 作为 `sourceInstanceId`，不得冒用目标单位或其他场上对象 ID。
- 成功结算顺序固定为：`CHOICE_RESOLVED`、`OBJECT_MOVED`、海晶碎片恢复 1 点生命、己方海豚向导移动增益、敌方守卫者移动反应、统一死亡结算。
- 治疗使用 `OBJECT_STATS_CHANGED`，`reason = HEAL`。即使目标原本满生命，也发布一次生命值不变的可回放效果事件。
- 成功移动会照常被视为移动事件，因此能触发海豚向导和敌方守卫者；治疗先于守卫者伤害结算。

## Unity 交互

- 选择海晶碎片后，仅让合法的己方水生单位通过 3D 模型/地表反馈发光。
- 锁定目标后直接显示相邻合法地块，不打开卡牌弹窗，也不显示“保持原位”按钮。
- 右侧材质化面板同时说明“移动后恢复 1 点生命”，以及尚未触发的敌方守卫者预计造成的伤害。
