# 雪傀儡雪球战吼规范 v1

本规范对应 `protocolVersion 25`、`rulesetVersion prototype-0.39` 与内容版本 31。

## SI-002 雪傀儡

- 雪傀儡是 `2` 费 `1/4` 傀儡生物。
- 成功部署并发送 `CARD_DEPLOYED` 后，战吼生成一张已注册的 `SI-001 雪球`，随后发送 `CARD_GENERATED`。
- 事件记录来源卡 `si_002`、来源战场实例、`effect.si_002.01`、最终目的区域和区域计数。
- 生成到手牌的雪球身份仅向拥有者投影；对手只知道雪傀儡生成了一张牌。
- 合法部署时雪傀儡先离开手牌，因此即使部署前达到七张上限，雪球也能进入刚腾出的手牌位置。
- 部署失败时不生成雪球、不扣费，也不产生部分事件。

## 教学闭环

- 玩家可以立即选择生成的雪球；雪球沿用已有定向卡牌流程，只高亮敌方存活单位所在的真实 3D 地表。
- 合法目标命令携带稳定实例 ID。结算后目标本回合获得 `-1` 攻击力，最低为 `0`，回合结束时恢复。
- 权威事件到达时，拥有者看到“凝聚雪球”横幅以及己方手牌/HUD 脉冲；对手反馈不得泄露雪球名称和卡图。

## 2.5D 表现

- 战场实体使用本机 Minecraft JAR 中的 `entity/snow_golem.png` 和分件体素模型，不使用通用生物占位模型。
- 模型由下层雪球、上层雪球、头部和两条树枝手臂组成，自动继承阵营朝向与战场透视。
- 卡面、手牌和右侧详情继续复用统一的 `CardUI` 材质化结构。

## 验收

- 服务端和 Unity 本地规则均按 `CARD_DEPLOYED → CARD_GENERATED` 生成 `SI-001`。
- 拥有者与对手事件投影满足隐藏信息边界，事件批次通过协议 Schema。
- 生成的雪球可以通过现有目标选择链路对敌方生物生效。
- Unity 使用雪傀儡专属 Minecraft 体素模型，并通过 EditMode 测试验证纹理映射。
