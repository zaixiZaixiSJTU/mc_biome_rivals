# 战场半场环境模块规范 v1

## 目标

战场背景由三个独立部分在运行时合成：己方近端半场、敌方远端半场、中立河道。双方群系可独立变化，7 个群系可组合出 49 种对局环境，不维护 49 张完整配对图。

## 资源契约

每个群系必须提供两种不可互换的视角资源：

- `field-{factionId}-v1.png`：`near`，仅用于己方近端。
- `field-{factionId}-far-v1.png`：`far`，仅用于敌方远端。

当前模块采用 1672 × 941 的全帧坐标锁定画布。无效半场仍保留参考内容，以确保河岸、相机投影和像素坐标完全一致；合成 Shader 只采纳对应的有效半场。

禁止通过纵向翻转 `near` 生成 `far`。翻转会同时反转砖块尺度、遮挡关系和消失方向，使两个半场呈现互相垂直的错误透视。

## 透视约束

- `near` 与 `far` 必须使用同一相机高度、俯角、焦距和消失关系。
- 深度方向的砖块行距与物体尺度必须向画面远端逐渐缩小。
- 中央河道位置固定在归一化画面高度 `0.5` 附近。
- 河岸结构可以形成浅沟，但不得表现为把两个独立俯视平面竖直拼接。
- 部署格不是背景图的一部分；它们是 3D Mesh，分别采样本方环境模块并继承主相机 MVP 变换。

## 运行时职责

`DemoBattlefieldThemeCatalog` 负责群系 ID 到 `near` / `far` 资源与环境色的稳定映射；`DemoBattlefield3D.SetBattlefieldThemes` 原子更新背景、双方部署格和环境灯光；`DemoCompositeBackdrop.shader` 只负责同坐标采样与中立河道混合，不执行镜像或透视补偿。

新增群系时，必须同时注册两张资源，并通过 EditMode 测试验证资源名、双方独立切换和远端材质引用。
