# 水流移动交互规范 v1

本规范对应 `protocolVersion 18`、`rulesetVersion prototype-0.21` 与内容版本 13。

## 公共位移约束

- 生物只可在自己的四格单位排内移动，目的地必须为空，且一次水流仅移动到相邻格。
- 服务器在触发时计算完整合法目的地，选择期间其他部署、施法、攻击、阶段推进与结束回合命令均被拒绝。
- `selectedOptionIndex = -1` 表示主动放弃移动；放弃不视为成功移动，也不触发移动后奖励。
- 选择快照保存目标玩家、目标实例、来源卡牌、来源实例与目的地编号；断线重连不能重新随机或重新计算出不同选项。
- 移动只改变单位格引用与对象的 `slotIndex`，不重置伤害、状态、召唤回合或攻击次数。

## OR-001 鲑鱼群

鲑鱼群从手牌成功部署后触发 `effect.or_001.01`。若左右至少有一个相邻空格，则进入 `MOVE_UNIT` 选择；没有合法相邻空格时不创建空选择。

成功移动后，鲑鱼群本回合获得 +1 攻击。该增益写入通用临时攻击字段，并在其控制者结束阶段恢复；保持原位时不获得增益。

## Unity 呈现

- 主行动阶段仍保持战场可见，不打开居中的卡牌选择遮罩。
- 鲑鱼群本体使用金色目标强调，合法的己方空单位格使用继承相机透视的 3D 地表高亮。
- 玩家直接点击发光地块移动；右侧材质化指令面板提供“保持原位”。
- 对手可看到位移来源、目标和结果，但其地块不可点击，选项的 `selectable` 投影为 `false`。
