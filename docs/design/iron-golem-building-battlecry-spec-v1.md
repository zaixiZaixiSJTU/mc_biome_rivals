# PF-008 铁傀儡建筑共鸣战吼规范 v1

本规范对应 `protocolVersion 23`、`rulesetVersion prototype-0.34` 与内容版本 26。

## 权威规则

- PF-008 是费用 6、基础 5/7、具有 `TAUNT` 的单位。
- 部署并完成入场成长后，检查其控制者是否拥有至少一个存活的 `BUILDING` 或 `STRUCTURE` 战场对象。
- 条件成立时，铁傀儡永久获得 `+1/+1`：攻击增加 1，当前生命与最大生命同时增加 1；多个建筑不会叠加该战吼。
- 条件不成立时仍正常部署为 5/7 嘲讽单位，不产生额外属性事件。
- 已死亡或生命为 0 的对象不满足条件；对手的建筑不满足条件。

## 协议与事件

- 成功强化时，在 `CARD_DEPLOYED` 及已有入场成长事件之后发布一个 `OBJECT_STATS_CHANGED`。
- 事件使用 `sourceCardId = pf_008`、`sourceInstanceId =` 铁傀儡实例、`effectId = effect.pf_008.01`、`reason = PERMANENT_STAT_MODIFIER`，并携带最终攻击、当前生命、最大生命与临时攻击字段。
- `PERMANENT_STAT_MODIFIER` 是协议 23 新增的明确原因值，用于攻击和生命同步永久变化；客户端不得把它当作临时增益或只更新生命。

## Unity 表现

- 本地演示与联机回放使用同一套最终 6/8 状态；联机客户端只消费服务端权威事件。
- 战吼成功时显示“建筑共鸣”提示并脉冲场上单位。
- 场上单位使用 Minecraft 铁傀儡实体纹理与体素模型，不使用通用占位方块。
