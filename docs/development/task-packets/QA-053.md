## 缺陷与修复

Unity Scene 原来的在线 DeployAsync 调用仍采用旧位置参数顺序，而 Session 已要求第四个参数为 handCardInstanceId。真实点击/拖放把 REDSTONE 发送为手牌实例 ID，后续支付和目标字段也错位。基础探针直接调用 Session，不能发现这个入口缺陷。现在 Scene 使用具名参数，准确传递手牌实例、支付方式、目标类型与目标实例；不改变协议或权威支付规则。

另一个实际缺陷：山羊的地表悬停/按下使用 EvaluateSelectedDeployment 验证邻接、跨边界及落点占用，点击却只执行通用部署检查。现在点击与拖放统一复用完整预览检查，红色禁用落点不会进入在线 dispatcher；服务端独立校验仍保留。
