# RULE-037 离线英雄攻击护甲结算对齐

更新时间：2026-10-02

## 目标与依据

修正离线演示与 Nakama 权威规则的英雄伤害差异。服务端 `damageHero` 按护甲优先规则吸收普通伤害；离线 `DemoLocalMatch.ApplyAttack` 之前在英雄直接攻击敌方英雄时仅减少生命，忽略目标护甲，且其他本地普通伤害分散维护各自的护甲扣减代码。

## 范围

- 引入单一本地英雄伤害入口，普通伤害先减少目标护甲，再将剩余伤害应用于生命，生命最低为 0；真实伤害绕过护甲。
- 攻击、反击、猪灵岩浆、末影水晶回合脉冲及自伤/疲劳共用伤害入口和英雄生命损失观察器；护甲完全吸收时不触发生命损失回调。
- 保留攻击命令合法性、英雄每回合只能攻击一次、武器耐久、场景反馈和权威联机规则不变。
- 不变更协议、Schema、服务端行为、卡牌数值或胜负规则。

## 验收

- 以攻击力为 2 的激流三叉戟分别攻击护甲 1 和护甲 3 的敌方英雄：前者护甲归零、生命减少 1；后者护甲减少 2、生命不变。两种情况下攻击均成功且装备耐久只消耗 1。
- 以 1 攻蜜蜂攻击护甲为 1/0 的敌方英雄：前者完全吸收、不扣生命且不触发敌方 Piglin 成长；后者生命减少 1 并触发 +1/+1 成长。
