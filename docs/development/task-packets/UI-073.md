## 实现

- DemoEntityBone新增BindPoseRotation；Parser分别保存rotation和bind_pose_rotation，两者同时存在也不丢字段。
- Builder自动将源绑定姿态作用于骨骼局部网格（含overlay），普通rotation仍作用于Transform并按真实父子层级继承。既有mesh override优先于source，北极熊现代源缺姿态的登记仍保留。
- 删除成人/幼体绵羊两套角度硬编码，改为通用source binding；UI-072的分层UV和落地保持。海龟body/eggbelly绑定无需新增角度特例，头/鳍留在原作者坐标帧。
