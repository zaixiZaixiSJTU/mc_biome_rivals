## 门禁

1. 非等边cube、非对称UV区域、非方atlas、mirror true/false，六面逐项检验区域与四角方向；验证镜像是否交换东西面，确认上下方向，保留几何坐标/法线/绕序/ZYX和binding契约。
2. 使用不对称颜色测试纹理在Unity真实GPU从六面采样，不能以Builder使用同一算法的自比较当独立证明；有实际失败才修对应实现，不凭不确定印象翻转贴图。
3. 全量EditMode、双Player来源/74卡图/诊断边界通过；144图逐hash比较，变化原尺寸看；实际受影响模型战场、原地块射线与基本交互回归。记录未覆盖per-face对象/全部动画的边界。
4. 更新日志/唯一路线图与失败、成功hash；随后原幼羊资产单独拆分，完整目标不能由这一切片关闭。

## 实施与独立依据

- 阅读固定 [Blockbench cube.js](https://github.com/JannisX11/blockbench/blob/e2ede0809ee6bc91f374ac7e00d34cffbdf86a14/js/outliner/types/cube.js) 的box UV布局及mirror交换东西面，与 [three_custom.js](https://github.com/JannisX11/blockbench/blob/e2ede0809ee6bc91f374ac7e00d34cffbdf86a14/js/util/three_custom.js) 的物理顶点一一对应；另以 [PrismarineJS Entity.js](https://github.com/PrismarineJS/prismarine-viewer/blob/7fa43a7317467a3ba84f857ba6b1ca9597c72b8c/viewer/lib/entity/Entity.js) 交叉核查非mirror各面。只参考行为，未复制代码/安装依赖。没有将Blockbench微小防串色偏移整包搬入。
- 已X镜像的Unity顶点要求默认U与当前corner顺序反向，mirror取消该反向且交换东西面region；底面V还需单独反向。仅改Builder上述UV，不改顶点/法线/绕序/ZYX/binding/材质/原素材。
- 数字参考fixture：size=2x3x4、uv=(5,6)、atlas=64x32。六面四角固定数字，另有实际Entity shader、线性RenderTexture、Point非对称纹理、四个内部位置采样。参考物理平面不读取生产mesh UV；测试将vertex color设白仅用于隔离面向明暗。
- 新增12项四角与12项GPU测试。初轮685总数/667通过/18失败，其中6个GPU案例失败；初轮U容差较宽，成功轮收紧到.01。UI-082旧北面测试自身遗漏X反射，明确更新期望值，几何与显式/继承mirror等价断言保留。
