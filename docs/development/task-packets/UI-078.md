## 源事实、实现及限制

- 固定Mojang commit `736072450c26a7c67f07b1661f29d9a5ebaa14b1`：[client entity](https://github.com/Mojang/bedrock-samples/blob/736072450c26a7c67f07b1661f29d9a5ebaa14b1/resource_pack/entity/sheep.entity.json)、[实际v2 render controller](https://github.com/Mojang/bedrock-samples/blob/736072450c26a7c67f07b1661f29d9a5ebaa14b1/resource_pack/render_controllers/sheep.v2.render_controllers.json)、[原geometry](https://github.com/Mojang/bedrock-samples/blob/736072450c26a7c67f07b1661f29d9a5ebaa14b1/resource_pack/models/entity/sheep.geo.json) 均已读取。羊毛派生记录的头为6×6×6、前沿-12/inflate .6，腿仅y6..12/inflate .5，body inflate1.75；UV位于同一64×64原TGA下半区，不是复制剪毛羊的脸/全长腿。
- 工厂显式登记overlay geometry；Parser新增单层legacy overlay提取，严格要求精确base/overlay ID、对应骨骼/pivot/parent且无独立rotation，缺失/不兼容明确失败。**不是通用legacy继承解释器**，普通Parse对派生ID继续拒绝。Builder将原外层cube挂到同一骨骼，保留源binding、UV、inflate、待机和两侧朝向；其他现有复制overlay路径保持。图册记录overlayGeometryId，来源可追溯。
- 第一轮几何修复的8图仍缺脸：原TGA为type10 RLE32位；只读解码确认脸/腿皮肤含alpha=3/255的棕色/黑眼像素，当前alpha裁剪剔除这些像素。官方[材质说明](https://github.com/MicrosoftDocs/minecraft-creator/blob/main/creator/Documents/material-files.md)（读取2026-10-04）说明sheep使用颜色遮罩材质；alpha用于染色权重而非透明。仅原羊皮肤登记 `_UseAlphaColorMask`，不裁剪该材质，RGB保持面向明暗、白羊染色默认白；不复用末影人发光策略、不强制所有模型opaque、不编辑纹理alpha。未实现染羊毛玩法或全部官方材质特性。
- `tk_003`仍为当前工程成人羊模型×.62的登记；本次修其羊毛/脸腿，**不是官方baby geometry/texture/比例动画完整实现**，图册自动取景会归一化显示尺寸，不能由两张大小相同的图推断场景缩放丢失。独立幼体资源管线仍属后续需求。
