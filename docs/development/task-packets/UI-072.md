## 根因与修复

- 本地已登记Bedrock绵羊body有bind_pose_rotation=[90,0,0]。原导入器把它当骨骼旋转，四腿随父节点横转。仅pf_002/tk_003覆盖body骨骼为零，将原绑定姿态烘焙到body网格；原Cube UV、子骨骼pivot和头部待机仍保留。
- 本地羊毛PNG为64x32，基础TGA为64x64，原叠层共用基础尺寸。OverlayLayer与EntitySpec显式配置独立atlas尺寸，零值仍继承原尺寸；两绵羊羊毛设64x32。
- 新回归又发现膨胀层最低点低于地面约0.071/0.044。新增GroundToBaseY opt-in，只开启两绵羊；其他生物的原偏移/缩放不变。
- 未修改/重提取/发布原始MC素材、卡框、群系场地或规则/协议。复用现有mesh-only绑定能力，不将参考项目代码直接复制进Unity。
