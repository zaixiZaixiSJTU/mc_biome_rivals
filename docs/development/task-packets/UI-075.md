日期：2026-10-04。状态：图册工具/本轮打包修复已完成；**不是所有生物外观验收通过**。后续异常处理见 UI-076。

## 交付与范围

- `DemoSceneController.EntityCatalogue.cs` 仅 Editor/Development 生成图册，启动参数 `-captureEntityCatalogue <新绝对目录>`。复用工厂注册、原 MC geometry/texture 和游戏 Entity 材质；禁止缺资产时用备用方块冒充成功。独立 layer 30 相机不渲染正常 UI/场景。
- 36 个卡牌登记（不是 36 个独立物种）×两侧朝向×固定待机时刻 0/0.23 秒，共 144 张 512×512 实图和六张 2048×3072 联系表。每页六行，列为己方0/己方0.23/敌方0/敌方0.23；排序按 cardId Ordinal。
- JSON 记录登记中文名称、ID、精确 geometry、模型资源 key、UTF8 geometry 文本 SHA、实际贴图尺寸、朝向、动画轨数、相机参数、联系表位置、单图 SHA。原资产文件 SHA 由对应 Player build manifest 记录；文本 SHA 不冒充原文件字节 SHA。
- `scripts/capture-entity-catalogue.ps1` 核验当前源码/Development 模式、目录不覆盖、进程退出码、144 张完整侧/相位覆盖、PNG 尺寸/单图 SHA 和六页 SHA。仅清理自己启动且超时的进程；所有图均是 Unity GPU 输出，无 AI/Python 重绘。
- 动画采样接口只在 Editor/Development 编译；正常 Update 仍按 unscaledDeltaTime 更新同一 ApplyPose。新增重复采样/归零/非法时间不改姿态测试。
- 范围是工厂模型的斜视角/骨骼待机检查，**不覆盖被遮挡六面、世界 Floater 位移、攻击动画或完整对局**。不同模型自动取景，不能用联系表显示大小证明幼体/成年比例正确。

## 实际发现并修复

首轮新 Player 启动明确报 `Real entity shader unavailable`、退出2、未输出伪成功图册。原因：Entity Shader 只通过运行时 Shader.Find 查找，没有场景序列化引用或 Always Included 项，构建时未保留；普通游戏材质 provider 会静默退回 Standard。

在 `ProjectSettings/GraphicsSettings.asset` 显式加入现有 DemoEntity.shader GUID，原材质/MC 资产/Shader 源码未修改。新增打包引用测试在旧设置 **608总/607通过/1失败**（matches=0），修复后 **608/608**、无跳过、CLI0。后续实际图册强制要求该 shader 存在且 supported，不能退回 Standard。
