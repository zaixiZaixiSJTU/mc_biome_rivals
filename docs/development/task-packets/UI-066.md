# UI-066 北极熊 Minecraft 模型基准姿态核查

更新时间：2026-10-04
状态：当前工作区功能与模型视觉门禁通过；独立提交树/发行及整体目标仍开放。

## 问题与范围

QA-055 普通雪原卡组准备过程中合法部署 SI-005 北极熊。standard_meadow 两端实图中北极熊身体呈竖直/柱状姿态，尚不能认定符合 Minecraft 四足基准站姿。证据：Temp/CurrentUnityCli/qa055-goat-matrix-verified/standard_meadow/online-arena-a.png 与 online-arena-b.png（各自 SHA 位于 validation.json）。

当前 DemoMinecraftModelFactory 将 si_005 映射到 geometry.polarbear / entity_polar_bear，TargetHeight=2，并给头/四腿添加 idle tracks，没有登记该实体的 BoneRotationOverrides。Builder 已支持 bone rotation/pivot 覆盖；是否缺失 vanilla 动画应用的基准姿态必须核对源 geometry/动画后再定，当前不宣称已确定根因。

本切片只修正并验证北极熊，不重写所有生物模型、不替换 MC 纹理、不更改卡牌数值/规则/协议、碰撞格位或整个场景相机。

## 入口与验收

- client-unity/Assets/Game/Demo/Runtime/DemoMinecraftModelFactory.cs：si_005 spec 与 idle tracks。
- DemoMinecraftEntityModelBuilder.cs：骨骼 parent/pivot/rotation 转换及 root bounds/缩放。
- 对应已登记 Minecraft 源 geometry/纹理和 vanilla 姿态依据；保持现有来源校验。
- 用 Unity 引擎新增静态骨骼/身体姿态/脚底与 bounds 回归，再运行全量 EditMode。数值断言须从源姿态推导，不为了通过测试随意猜角度。
- 用同来源的新 Development Player，在双方视角、1280/1920 查看真实北极熊模型，确认四足基准姿态、idle 不破坏基准、格位位置/鼠标命中不变且不遮挡手牌/HUD；记录来源清单、日志、退出码和截图哈希。
- 不用旋转整个根节点、换成自制方块近似物或关闭动画来掩盖问题。若必须增加 pose 数据，只对该模型登记，可审查且可复用。

推进顺序：先结束 ARENA-037E2d 的独立服务端非法命令验收，再进入本视觉切片。整体 UI/游戏性目标保持开放。
