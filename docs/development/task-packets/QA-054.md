首轮实际 1920 截图发现四建筑格仍沿用三格的 4.35/4.5 格距，末端模型被右侧详情 HUD 局部遮挡。有效引擎红测两项均失败，首端 X=-6.525 而标准外锚点应为 -4.35。现在仅四建筑格排压缩到 2.90/3.00 格距，外锚点与标准三建筑格排一致；2.85 宽的地表仍保留物理间隙，标准三格/两格和单位排不改。多格 mesh 的中心与宽度继续从实际占格位置计算，没有单独缩放模型来掩盖错位。
