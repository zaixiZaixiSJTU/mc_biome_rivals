## 分项验收（全部满足前不关闭总目标）

1. HUD 材质与信息层级：石砖只用于边缘，黑石正文低噪声，不受群系底色影响；普通按钮中性、主要动作明确；材质不退化成无纹理 Web 黑框。当前先修复九宫格中心纹理透过正文的双层叠加。
2. 卡面与阅读：七主题一致，费用/攻防/状态辨识明确；满手牌、长正文、详情和图鉴排版无截断或错误。摘要必须明确区分全文。
3. 布局与可访问性：实际 1280×720、1920×1080、超宽和窗口缩放下验证可读字号、遮挡、焦点/键盘导航和不只依赖颜色的状态提示；数学断言不能替代实际渲染。
4. 玩家入口与界面闭环：明确的开始/模式/对局操作入口，设置、帮助、暂停/退出、连接等待/失败/重连、胜负返回；将演示/诊断信息与玩家信息分离，不移除调试能力。
5. 交互与动效：悬停、点击、拖动、非法动作、支付、攻击、伤害、死亡、回合推进具有一致、克制且不阻断操作的反馈；补验禁用、模态和终局状态。
6. 最终运行验收：当前源码引擎回归、双构建来源/资源/诊断隔离、真实基础对局及逐项原尺寸视觉证据；记录未完成项，不以测试总数证明美观。
