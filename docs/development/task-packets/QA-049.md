- 双方强制断线并从同一 Match/revision 恢复；拥有者恢复精确折扣和到期归属，观察者始终只得等量 null 占位。拥有者检查真实手牌/详情 CardUI 绑定的实例和费用，结束回合后同一实例费用恢复。
