## 对照事实与实现

- 固定Mojang `736072450c26a7c67f07b1661f29d9a5ebaa14b1` 的[cave spider client](https://github.com/Mojang/bedrock-samples/blob/736072450c26a7c67f07b1661f29d9a5ebaa14b1/resource_pack/entity/cave_spider.entity.json)、[默认动画](https://github.com/Mojang/bedrock-samples/blob/736072450c26a7c67f07b1661f29d9a5ebaa14b1/resource_pack/animations/spider.animation.json)、[动画controller](https://github.com/Mojang/bedrock-samples/blob/736072450c26a7c67f07b1661f29d9a5ebaa14b1/resource_pack/animation_controllers/spider.animation_controllers.json) 已读取：默认状态始终播放default_leg_pose，walk依速度。原本地geometry八腿无初始rotation，程序只有3度待机摆动，因此腿一直重叠。工厂登记原八腿角度（yaw ±45/±22.5，roll ±45/±33.3），按原零rotation状态求静态default_leg_pose；未实现通用Molang或完整行走/目标注视动画。
- 固定Blockbench `e2ede0809ee6bc91f374ac7e00d34cffbdf86a14` [legacy导入](https://github.com/JannisX11/blockbench/blob/e2ede0809ee6bc91f374ac7e00d34cffbdf86a14/js/formats/bedrock/bedrock_old.js) 与[动画导入](https://github.com/JannisX11/blockbench/blob/e2ede0809ee6bc91f374ac7e00d34cffbdf86a14/js/formats/bedrock/bedrock_animation.js) 均对X镜像并转换X/Y角度；阅读PrismarineJS通用实体构造作另一个坐标实现对照，但不直接套其未镜像网格的符号。用独立中心坐标解析式测试证明本地原转换(-X,+Y,-Z)错误，统一改为(-X,-Y,+Z)，骨骼/数组cube/scalar-axis cube同一契约，保留现有XYZ顺序和mesh-only绑定分离。未复制GPL/MIT代码、未安装新依赖。
- 蜘蛛继续2.2目标宽度/.9战场可读性缩放，不冒称官方client .7实体尺度完全一致。原腿默认姿态启用既有GroundToBaseY，脚底到地表；八腿待机围绕修正后的初始姿态，原pivot/UV/cube不变。
