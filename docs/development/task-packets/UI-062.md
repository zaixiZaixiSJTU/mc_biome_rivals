# UI-062 战斗操作提示最小屏幕字号

更新时间：2026-10-02

## 目标

在保留 Minecraft 像素 UI 比例与原 1920 参考布局的前提下，避免小画幅缩放后右侧战斗指令正文变得过小，帮助玩家辨认下一步输入。

## 范围

- 仅对战斗阶段右侧 `CombatHint` 说明设置最小 12 屏幕像素字号。
- 参考 Canvas 缩放为 1 时维持现有 15 设计字号；更小画幅按 `Canvas.scaleFactor` 换算到足够的设计字号并向上取整。
- 共享换算放入 `DemoUiMetrics`，对零/极小 scale factor 设保护。
- 不改面板 Sprite、石砖纹理、布局尺寸、文案、战斗逻辑或其他固定 UI 标签。

## 验收

- EditMode 覆盖 1.0、2/3、0.5 缩放，预期字号分别是 15、18、24 设计单位。
- 当前源码 Development Player 的战斗交互预览在 1280×720 与 1920×1080 均无文案裁切、输入链通过，并核验构建源码清单、日志、退出码及截图尺寸。

## 完成状态

**已完成。** Unity CLI `1.0.0-beta.8` / Editor `6000.0.28f1c1` 隔离工程 EditMode **359/359 Passed**，NUnit XML：`Temp/CurrentUnityCli/ui062-combat-hint-editmode.xml`。Windows Development Player 由 Unity CLI 构建，630 项来源清单通过；1280×720 和 1920×1080 截图/交互验收通过，哈希见 `docs/development/change-log.md`。
