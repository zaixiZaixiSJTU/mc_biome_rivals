# AI-086 全玩家操作接口与基础权威 AI 客户端

日期：2026-10-04。状态：本项已实施并验证；复杂策略规划、全效果实战与单进程离线双人引擎不在本项完成范围。

## 需求与实现

用户要求为所有玩家操作提供接口供 AI 人机对战。本项覆盖现有8个规则命令，不把无协议依据的作弊/调试或视觉点击当玩家操作。

- Networking：IPlayerOperations、PlayerObservation、PlayerActionRequest、IMatchAgentPolicy、MatchAgentRunner。观察为不可变JSON/每次独立DTO，强制隐藏敌方手牌/私有选项；同对局/版本、待确认、空payload/未知动作、数组冻结和服务端结果。
- DemoOnlineMatchSession 实现接口，复用现有dispatcher/gateway与服务端规则；UI原typed调用继续共用此边界，不复制伤害/支付逻辑。协议40/prototype-0.65/内容42/效果48不变，无新增RPC/服务器部署。
- BasicMatchAgentPolicy 与 DemoSceneController.Agent partial：公开SetAgentPolicy替换/停止；CLI -aiPlayer + -autoOnline；非Development可用。每0.4秒至多一次决策，等待ACK，同revision不盲目重试、停用不销毁session。
- 基础策略可调度、部署无需指定目标的单位/建筑、红石/合成支付、首个可选项、准备度/嘲讽约束攻击与结束回合；暂不规划法术/多目标/指定战吼/复杂组合。接口覆盖≠策略善用全卡；没有假称DemoLocalMatch的演示假对手变成公平双视角引擎。
- 新validate-ai-player脚本仅创建自己的测试客户端/账号/对局，保留证据、结束自己创建的进程、恢复进程环境；不重启/部署服务或数据库管理写入。runtime-boundary新增六个生产AI类型和SetAgentPolicy方法，仍检查原20诊断类型隔离。

完整参数、8命令表、C#/启动示例见 [接口文档](../ai-player-operations.md)。
