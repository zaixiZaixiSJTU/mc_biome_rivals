依赖：UI-048/049/050、UI-064。仅修改 Unity 呈现/交互与验收夹具，不改变服务端结算、协议、卡牌数值或内容注册。

## 缺口与实现

原终局流程已锁定手牌、回合与英雄按钮，但其他建筑/烈焰人仍能显示效果就绪，海底神殿威胁和旧目标选择也缺少统一终局清理。多格部署的悬停/按下状态不能靠指针单格的退出回调完整释放。

- `ResolveSlotEngineReadyKind` 集中保留现有 12 种效果判断，并先拒绝终局、缺失或已死亡的来源；双方共用相同门禁。
- `RefreshAllInternal` 在终局禁用场景指针，清除卡牌/具体手牌副本、攻击者、部署目标和法术目标选择。指针同时清理缓存的按下/悬停，释放后不会补发点击。
- `DemoBattlefield3D.ClearSlotInteractions` 清理所有格位的合法/优先目标、悬停/按下和拒绝反馈，包含多格范围；不会删除最终棋子、生命数据、被动光环、状态或有限时长的事件脉冲。
- 海底神殿威胁判断停止；效果铭牌不再在终局显示待触发、等待出土、监听敌方或就绪提示。府邸/要塞继续使用 UI-064 的“对局已结束”；其他名称、数值和被动状态保留。
- `HasActiveGameplayHighlights` 提供只读场景诊断，统计输入/目标/效果就绪/结束阶段威胁，不把被动状态及短暂事件反馈当作可操作提示。
