# UI-063 欠费手牌保持卡面可读

更新时间：2026-10-02

## 目标

欠费手牌仍需明显区别于可支付手牌，但不应把 Minecraft 卡图、费用槽和规则正文同时洗淡到难以辨认。选中后详情面板继续提供准确费用差额，卡牌本身保持可选、可检查和可拖动。

## 实现范围

- 将 `CardUI.SetResourceAffordable(false)` 的整体透明度从 0.62 提升为 0.8；可支付仍为 1.0。
- 不改变资源计算、合法性校验、手牌选择、GraphicRaycaster、拖放或支付结果。
- 保留 UI-054 的红石差额提示作为具体解释，整体透明度只承担轻度视觉提示。

## 验收

- EditMode 验证欠费卡透明度为 0.8、仍可交互并接收射线；恢复可支付为 1.0；再次欠费不会累积透明度。
- Unity CLI 全量 EditMode 通过。
- 隔离副本 Windows Development Player 在 1280×720 与 1920×1080 通过欠费卡真实点击/详情预览；核对截图、运行日志、源码清单与画幅，并目视确认卡图和正文比原 0.62 状态更清楚、欠费状态仍易区分。
