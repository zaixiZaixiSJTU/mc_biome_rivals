# UI-092 阅读键盘路由与焦点标记

日期：2026-10-05。状态：源码交付中的局部功能；不等于实际操作系统键盘或完整可访问性验收。UI-087总目标仍进行中。前一切片的卡牌可读性、全卡代表图与历史联机证据见[UI-091](UI-091.md)。

## 实施与固定约束

- `DemoUiNavigation`集中管理合法控件过滤、正反向Tab循环、返回焦点和滚动边界。禁用、隐藏及CanvasGroup锁定控件不得获得焦点；切换焦点不触发点击或游戏命令。
- `DemoUiFocusIndicator`用浅色像素角标和暗色衬底标出当前合法选择，形状而非仅颜色表达焦点。图层不接收射线，随Canvas缩放维持屏幕尺寸；只重用有效直系子对象，不重用已停用、等待销毁的旧卡牌图层。
- `DemoSceneController.Update`接入Tab/Shift+Tab；只读图鉴内限定在返回、上一张、下一张之间循环，状态全文仅返回按钮。方向键处理图鉴翻牌与正文滚动，PgUp/PgDn翻屏、Home/End首尾、Esc或右键返回。阅读控件禁用UGUI自动方向导航，避免同一次方向输入同时翻牌和移动焦点；UGUI提交事件仍保留。
- 只读期间不解锁手牌、战场、结束回合或待决确认。相同卡ID的手牌按稳定实例翻页；待决阅读同时绑定choiceId与optionIndex，返回时重新查找UI重建后的同一选项入口，不凭重复卡名恢复焦点。
- 待决选项失效时关闭阅读并清理旧缓存；即使另一个相同cardId仍存在，也不能保留旧选项阅读。返回焦点在控件可用性更新后恢复，只选合法入口。没有修改费用、规则、注册版本或AI操作契约。
