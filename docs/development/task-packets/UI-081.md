## 原因与实现

- 固定Mojang `736072450c26a7c67f07b1661f29d9a5ebaa14b1` 的[blaze client](https://github.com/Mojang/bedrock-samples/blob/736072450c26a7c67f07b1661f29d9a5ebaa14b1/resource_pack/entity/blaze.entity.json)、[animation](https://github.com/Mojang/bedrock-samples/blob/736072450c26a7c67f07b1661f29d9a5ebaa14b1/resource_pack/animations/blaze.animation.json)、[controller](https://github.com/Mojang/bedrock-samples/blob/736072450c26a7c67f07b1661f29d9a5ebaa14b1/resource_pack/animation_controllers/blaze.animation_controllers.json) 已读取：default状态持续播放move与look_at_target；十二棒的环由position实现，不是改pivot。原BlazeRodPivots只重设旋转轴，网格构造减去同一新pivot，初始坐标抵消，杆仍在中央重叠；25条旧近似摆动无法构成三层棒环。
- 删除工厂错误pivot覆盖/近似环参数；十二骨骼保留原pivot(0,24,0)、原cube/UV。先按原t=0位置offset展开再fit，3层半径9/7/5像素、角速度-360/+108/-180度每秒、相位偏移0/45/27度，每层4根。上下浮动复用原cos参数（286.4度每秒与逐杆相位）。统一SourceOrbitSpec显式位置轨道，Animator按t与t=0之差作用于初始位置，避免重复偏移或累计漂移；源X镜像转换仅一次。不需要新运行时包，不复制开源代码，不改共用ZYX/binding契约。
- 旧24条杆位移/旋转近似替换为12条原参数位置轨道，头部既有5度待机保留，总13条；仍2.05目标高度，底部t=0距地.3防止浮动穿地。独立解析式逐杆检查双侧/t0/t.23位置、原mesh中心(-1,-4,1)/16、13原cube、不错误旋转杆、采样回零与离地；不是仅非空mesh测试。
- 这是原公式专用适配，时钟采用项目实体局部unscaled时间，不实现通用Molang、世界query.life_time/注视目标、charged火焰粒子或原版body/head不同材质。现有Entity材质/火焰亮度近似保持，不称完整原版渲染等价。
