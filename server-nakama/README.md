# Nakama Server Module

`src/rules` 是纯规则核心；`src/matches` 和 `src/rpc` 是 Nakama 边界适配器。构建产物只有 `build/index.js`，供 Docker 容器加载。

先后手由可回放的对局种子决定，不依赖玩家进入房间的先后顺序。

当前实现工程闭环需要的 30 张牌库、先手 3 张/后手 4 张起手、双方各一次任意数量调度、首回合抽牌、7 张手牌上限、公开爆牌、递增真实疲劳、开局快照、卡牌部署、主行动/战斗阶段、普通攻击、同步反击、死亡离场、英雄伤害/护甲、胜负、结束回合和认输。调度时先暂时移出所选卡、抽取等量替换牌，再把原牌洗回隐藏牌库；双方确认前权威状态保持 `MULLIGAN`，普通对局命令不会生效。稳定 `effectId` 注册表现已接入 17 个效果：`粉雪桶`会对敌方生物施加公开的`缓慢`状态，禁止普通攻击并绑定 -2 攻击，直到目标控制者的结束阶段统一移除；重复施加不叠加，快照和事件都会记录来源与剩余持续时间。`可疑的沙子`会将`陶片`洗入隐藏牌库并获得护甲；陶片出土时公开进入手牌（满手则进弃牌堆）、获得护甲，再继续本次正常抽牌；`沙漠考古学家`会私下查看牌库顶三张，只允许拥有者选择其中带掩埋标记的一张出土，选择完成前锁定其他行动；任一方式完成出土后，`恶地劫掠者`在本回合的红石费用由 3 降至 2，回合结束立即恢复。其余已接入效果包括`蜜蜂`战吼治疗、`沙尘暴`全场生物伤害、`熔岩献祭`、`雪球`、`腐肉`、`骨头`友方临时增攻、`圆石`建筑治疗、`潜影壳`、`潜影贝`亡语与`岩浆怪`亡语。潜影贝死亡时生成 `tk_016`；手牌未满时只向拥有者投影卡牌身份，满手时直接进入公开弃牌堆。岩浆怪死亡时通过公开 `OBJECT_SUMMONED` 生成 `tk_014`，优先占用来源释放的单位格。尸壳、放牧绵羊与地牢骷髅仅在被敌方控制的攻击、反击或伤害击杀时，分别向击杀者生成 `tk_005`、`tk_001` 与 `tk_009`。地牢骷髅先从当前合法敌方生物中确定性选取并记录一个随机目标造成 1 点亡语伤害，再结算自身掉落；亡语造成的新死亡进入下一批检查。死亡结算会先移走同批双方全部死亡对象，再按当前玩家、非当前玩家顺序处理亡语，并在每批后重复死亡检查；同一控制者的手动排序命令尚待接入，当前按单位格从左到右确定性执行。目标会在付款前按敌我关系、对象类型和稳定实例 ID 校验；临时增减攻由权威状态记录并在施法者回合结束时通过独立事件恢复。基础关键词 `TAUNT` 与 `CHARGE` 已成为公开战场状态：多个存活嘲讽目标会共同屏蔽英雄和非嘲讽对象，冲锋允许生物在召唤回合攻击。其余效果会在支付费用前明确拒绝。战场格保存稳定实例 ID，多格结构的多个连续格引用同一个状态对象；权威测试覆盖边界/重叠拒绝、攻击只命中一次、结构不反击，以及三格结构死亡后一次释放完整范围。抽牌、调度、生成到手牌和牌库查看事件按接收玩家单独投影，对手只能看到未知手牌位与隐藏的选择占位；完整牌库顺序不离开服务端。当前 74 张机制验证卡不足以组成满足同名上限的完整单阵营牌组，因此匹配初始化暂用 30 张可复现的群系测试牌序；构筑校验仍待接入。当前卡池已有 4 张嘲讽牌，但还没有正式冲锋卡牌；不可指定状态与其余具体卡牌效果仍待实现。新增规则时先写规则测试，再接 Match Handler，避免把领域逻辑写进网络回调。

两名客户端加入 Nakama matchmaker 时必须通过字符串属性 `factionId` 提交七个已注册群系之一。`biomeRivalsMatchmakerMatched` 会校验人数、用户 ID 与群系值，并把用户到群系的映射传入 `nk.matchCreate('biome_rivals')`，确保返回的是权威 Match Handler，而不是同名中继房间。Match Handler 按该映射建立可复现的群系测试牌序，不能根据连接先后猜测玩家阵营。

协议 opcode：`1` 命令、`2` 事件批次、`3` 命令拒绝、`4` 权威快照。协议结构以 `shared-schema/protocol` 为准。

当前基础对局纵向切片使用 `protocolVersion: 15` 与 `rulesetVersion: prototype-0.18`。v15 在公开战场对象中加入可重连的状态数组，并新增状态施加/移除事件；`prototype-0.18` 接入 SI-006 粉雪桶：对敌方生物施加 1 次控制者结束阶段的缓慢，期间禁止普通攻击并绑定 -2 攻击修正。同名状态不叠加，重复施加取较长持续时间；状态到期时修正与状态在同一权威事件链中恢复。旧规则集客户端不能静默兼容。

运行：

```powershell
npm test
npm run build
```
